# Utilities (`utils`)

## Overview
Core application utility layer (`com.drliki.MusicLi.utils`) providing album art extraction/caching/URI resolution, lyrics parsing/validation/romanization, Media3 `MediaItem` construction and MediaStore/file operations, audio metadata & genre parsing, crash/logging/tracing diagnostics, locale/shortcut/orientation/screen-awake/battery policies, playback speed and queue shuffle helpers, and ZIP sharing.

## Invariants
- **Album Art & Cache Generation**: `[AlbumArtCacheManager.kt:AlbumArtCacheManager.cleanCacheIfNeededInternal]` serializes cleanup behind `cleanupMutex`, throttles runs to `MIN_CLEANUP_INTERVAL_MS` (5 min), excludes `_no.jpg` markers from size/count/eviction, and evicts `25%` (min 1) oldest `song_art_*` files when total exceeds `maxCacheSizeBytes`; `[AlbumArtUtils.kt:AlbumArtUtils.ensureAlbumArtCachedFile]` only writes cached art or `_no.jpg` markers when the captured generation matches `artworkCacheGeneration.get()` under `artworkCacheWriteLock`; `[AlbumArtUtils.kt:AlbumArtUtils.boundArtworkForCache]` re-encodes oversized art (`> 1536 px` or `> 900 KB`) as JPEG 90; `[ArtworkTransportSanitizer.kt:ArtworkTransportSanitizer.sanitizeEncodedBytes]` returns `null` for empty/undecodable bytes and skips re-encoding if within `maxDimensionPx` and `maxBytes`; `[LocalArtworkUri.kt:LocalArtworkUri.isLocalArtworkUri]` recognizes both `pixelplayer_local_art://` and legacy `pixelplay_local_art://`.
- **Folder Artwork & Directory Rules**: `[AlbumArtUtils.kt:AlbumArtUtils.isFolderAlbumArtEnabled]` requires both preference and runtime image permission (`[FolderArtworkPermissions.kt:folderArtworkPermissions]`); `[FolderArtistArtUtils.kt:FolderArtistArtUtils.findArtistImage]` checks at most two matching parent directories and rejects symlinks whose `canonicalFile.parentFile != directory`; `[FolderArtworkSettingsCoordinator.kt:FolderArtworkSettingsCoordinator.update]` serializes under `mutex` and persists `folderAlbumArtCacheState` only after cache invalidation completes; `[DirectoryRuleResolver.kt:DirectoryRuleResolver.isBlocked]` overrides blocks whenever an allow rule has `>=` prefix length.
- **Lyrics Parsing & Import Security**: `[LyricsImportSecurity.kt:LyricsImportSecurity]` restricts extensions to `.lrc` (max 256 KB) and `.ttml` (max 1 MB), checks allowed MIME types, enforces strict BOM/UTF-8 decoding (`CodingErrorAction.REPORT`), blocks `<!DOCTYPE` in TTML, and caps text at `50_000` chars; `[TtmlLyricsParser.kt:TtmlLyricsParser.parseToEnhancedLrc]` rejects `<!DOCTYPE`/`<!ENTITY`, caps `<p>` elements at `5_000`, disables external DTD/entity resolution, and sorts output chronologically; `[LyricsUtils.kt:LyricsUtils.parseLyrics]` normalizes to NFC, routes TTML/Kugou/LRC by format, pairs at most one same-timestamp translation per voice, and emits `[bg:...]` before translations in `toEnhancedLrc`; `[LyricsUtils.kt:MultiLangRomanizer.romanizeLine]` evaluates scripts in order Japanese -> Chinese -> Korean -> Indic -> Cyrillic (`Katakana-Latin; Lower` ICU transliterator requires API >= Q).
- **Media3, MediaStore & Files**: `[MediaItemBuilder.kt:MediaItemBuilder.shouldPreferDirectLocalFileUri]` enables direct `file://` URIs only for local `content://` paths matching supported MIME/extensions, and `[MediaItemBuilder.kt:MediaItemBuilder.isInsideAppStorage]` restricts external controller `FileProvider` wrapping to `cacheDir`/`filesDir`; `[MediaMetadataRetrieverPool.kt:MediaMetadataRetrieverPool.acquire]` creates a fresh `MediaMetadataRetriever` per call (`poolSize() == 0`) and `withRetriever` always releases it; `[MediaStorePermissionHelper.kt:MediaStorePermissionHelper]` validates positive IDs and falls back to per-URI probing on batch `createDeleteRequest` failure; `[MediaStoreSelectionUtils.kt:buildLocalAudioSelection]` clamps `minDurationMs >= 0` and exempts MIDI from the duration floor; `[FileDeletionUtils.kt:FileDeletionUtils.deleteFile]` uses only `ContentResolver.delete` on API 30+.
- **Playback Speed, Queue & Policies**: `[PlaybackSpeedUtils.kt:PlaybackSpeedUtils]` uses integer hundredths clamped to `[25, 300]` (`0.25f..3.00f`); `[QueueUtils.kt:QueueUtils.buildAnchoredShuffleQueue]` keeps the anchor at `anchorIndex` (or index `0` when `startAtZero = true`) and yields every 512 items in suspending mode; `[NetworkRetryUtils.kt:NetworkRetryUtils.withNetworkRetry]` never retries `CancellationException` and only retries `IOException` or `HttpException` (`429` or `>= 500`); `[PhoneOrientationPolicy.kt:PhoneOrientationPolicy.apply]` locks `smallestScreenWidthDp < 600` to portrait unless overridden; `[ScreenAwakePolicy.kt:shouldKeepScreenAwake]` is true iff `preferenceEnabled && isPlaying`; `[ZipShareHelper.kt:ZipShareHelper.createAndShareZip]` fails on empty song lists and deduplicates entry names case-insensitively.
- **Diagnostics & Text**: `[LogUtils.kt:LogUtils]` caps tags at 23 chars and prefixes thread names; `[TraceUtils.kt:traceSection]` / `traceAsyncSection` always pair `begin*`/`end*` in `finally`; `[CrashHandler.kt:CrashHandler.uncaughtException]` always delegates to `defaultHandler`; `[Extensions.kt:repairUtf8Mojibake]` only repairs strings with mojibake lead chars where strict Windows-1252 -> UTF-8 roundtrip succeeds; `[GenreParser.kt:GenreParser]` splits on `;`, `,`, `|`, `\`, `\u0000` (preserving `/` and `&`) and filters source placeholders in `dominantGenre`.

## Side Effects
- **Disk & Cache I/O**: `[AlbumArtUtils.kt:AlbumArtUtils]` and `[AlbumArtCacheManager.kt:AlbumArtCacheManager]` create/read/write/delete `song_art_*` and `_no.jpg` files in `filesDir/album_art`, migrate legacy `cacheDir` art, and mutate `_artworkCacheVersion`; `[ZipShareHelper.kt:ZipShareHelper]` reads song streams and writes/cleans temporary ZIPs in `cacheDir/shared_zips`; `[FileDeletionUtils.kt:FileDeletionUtils]` deletes media files via `ContentResolver` or `File.delete()`; `[LyricsImportSecurity.kt:LyricsImportSecurity]` reads `InputStream`/`File`; `[FolderArtistArtUtils.kt:FolderArtistArtUtils]` lists parent directories.
- **SharedPreferences, Repositories & Caches**: `[AppLocaleManager.kt:AppLocaleManager]` writes `"app_locale_preferences"`, updates `Locale.setDefault`, mutates `applicationContext.resources`, and calls `AppCompatDelegate.setApplicationLocales`; `[CrashHandler.kt:CrashHandler]` installs the global `UncaughtExceptionHandler` and persists `"crash_handler_prefs"`; `[AppShortcutManager.kt:AppShortcutManager]` updates `UserPreferencesRepository` and `ShortcutManagerCompat` dynamic shortcuts; `[FolderArtworkSettingsCoordinator.kt:FolderArtworkSettingsCoordinator]` mutates preferences, clears image/artist/color caches, and optionally starts `syncManager.fullSync()`.
- **System IPC, Intents & Process State**: `[MediaStorePermissionHelper.kt:MediaStorePermissionHelper]` and `[MediaStoreGenerationUtils.kt:readExternalMediaStoreGenerations]` issue `ContentResolver`/MediaStore IPC calls; `[StorageUtils.kt:StorageUtils]` queries `StorageManager` (with reflection fallback); `[ZipShareHelper.kt:ZipShareHelper]` and `[BatteryOptimizationIntents.kt:openBatteryOptimizationSettings]` launch Android `Activity` intents; `[PhoneOrientationPolicy.kt:PhoneOrientationPolicy]` mutates `Activity.requestedOrientation`; `[MediaMetadataRetrieverPool.kt:MediaMetadataRetrieverPool]` and `[AudioMetaUtils.kt:AudioMetaUtils]` allocate/release native extractors/retrievers; `[LyricsUtils.kt:MultiLangRomanizer]` mutates `preferredIndicStyle` and temporarily swaps `contextClassLoader` when initializing Kuromoji; `[TraceUtils.kt:traceSection]`/`traceAsyncSection` emit `android.os.Trace` events; multiple utilities log via `Timber`.
