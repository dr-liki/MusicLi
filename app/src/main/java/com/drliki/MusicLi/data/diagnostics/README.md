# diagnostics

## Overview
Process-wide performance telemetry, main-thread frame stall monitoring, opt-in timed diagnostic event recording, and JSON/plain-text debug performance report generation.

## Interface
- `[PerformanceMetrics.kt:PerformanceMetrics]`: Singleton telemetry registry (`Timings`, `Counters`, `Maxes`, `LARGE_ARTWORK_BYTES = 1_000_000L`, `TimingStat`, `TimingSnapshot`, `OffloadEvent`, `ControllerInfo`, `Snapshot`, `widgetActive`) exposing `recordTiming`, `time`, `increment`, `recordMax`, `recordEmbeddedArtwork`, `recordDecodedArtworkDimensions`, `recordPlaybackFormat`, `recordOffloadFallback`, `recordControllerConnected`, `setWidgetActive`, `snapshot`, and `resetForTest`.
- `[AdvancedPerformanceDiagnostics.kt:AdvancedPerformanceDiagnostics]`: Opt-in diagnostic session logger (`MAX_EVENTS = 120`, `DEFAULT_SESSION_DURATION_MS = 24h`, `FRAME_STALL_THRESHOLD_MS = 100L`, `EventTypes`, `DiagnosticEvent`, `Snapshot`, `isEnabled`) exposing `startSession`, `configureSession`, `stopSession`, `recordEvent`, `recordEventIfEnabled`, `markLagNow`, `trace`, `traceSuspend`, `snapshot`, and `resetForTest`.
- `[AdvancedPerformanceDiagnosticsController.kt:AdvancedPerformanceDiagnosticsController]` & `[AdvancedPerformanceDiagnosticsController.kt:shouldRunMainThreadStallMonitor]`: `@Singleton` lifecycle coordinator connecting `UserPreferencesRepository` diagnostic session preferences and app foreground state (`start`, `onAppForeground`, `onAppBackground`) to `MainThreadStallMonitor`.
- `[MainThreadStallMonitor.kt:MainThreadStallMonitor]`: `Choreographer.FrameCallback` monitor emitting `EventTypes.FRAME_STALL` events when consecutive frame intervals meet or exceed `thresholdMs` (`start`, `stop`).
- `[DebugPerformanceReport.kt:DebugPerformanceReport]`: `@Serializable` report model (`SCHEMA_VERSION = 3`, `DeviceSection`, `AppSection`, `LibrarySection`, `HiResSection`, `ArtworkSection`, `PlaybackSection`, `ControllerSection`, `ConnectedController`, `ReportTiming`, `OffloadEventEntry`, `AdvancedDiagnosticsSection`, `AdvancedDiagnosticEventEntry`) with `toJson`, `toPlainText`, `bytes`, and `pcmEncodingLabel`.
- `[DebugPerformanceReportCollector.kt:DebugPerformanceReportCollector]`: `@Singleton` collector (`generate`) aggregating device/RAM info, `MusicDao` library stats, active player/decoder state, equalizer/output preferences, `PerformanceMetrics`, and `AdvancedPerformanceDiagnostics` into a `DebugPerformanceReport`.

## Invariants
- `[AdvancedPerformanceDiagnostics.kt:AdvancedPerformanceDiagnostics]`: Returns immediately on a volatile `isEnabled` check when disabled (`recordEvent`, `recordEventIfEnabled`, `trace`, `traceSuspend`); `startSession` clamps `durationMs` to `>= 1L`; `configureSession` activates only when `enabled && startedAtEpochMs != null && expiresAtEpochMs != null && nowEpochMs < expiresAtEpochMs`, clearing events when session bounds change or expire; `events` deque is bounded to `MAX_EVENTS` (`120`) under `lock`, truncating fields to `80` chars, detail values to `240` chars, detail maps to `8` entries, and trace section names to `120` chars with `Trace.endSection()` guaranteed in `finally`.
- `[AdvancedPerformanceDiagnosticsController.kt:AdvancedPerformanceDiagnosticsController]`: `start(scope)` is idempotent while `observerJob != null`; `shouldRunMainThreadStallMonitor` requires `sessionActive && appForeground`; monitor start/stop dispatches on `Dispatchers.Main.immediate` guarded by monotonically increasing `monitorUpdateGeneration` (`AtomicLong`) so stale updates are ignored.
- `[MainThreadStallMonitor.kt:MainThreadStallMonitor]`: `start()` and `stop()` are idempotent via `running`; emits `FRAME_STALL` only after a previous frame (`previous > 0L`) when `(frameTimeNanos - previous) / 1_000_000L >= thresholdMs`.
- `[PerformanceMetrics.kt:PerformanceMetrics]`: Ignores negative timings (`< 0`) and non-positive maxes/artwork bytes (`<= 0`); `TimingStat.snapshot()` returns `null` when `count == 0L`; `recordPlaybackFormat` records `PLAYBACK_PCM_ENCODING` only if `pcmEncoding > 0` and increments `MULTICHANNEL_PLAYBACKS` only if `channelCount > 2`; `offloadEvents` caps at `MAX_OFFLOAD_EVENTS` (`20`); `recordControllerConnected` deduplicates by `packageName` and sorts snapshots by `firstSeenElapsedMs`; forwards `recordTiming` to `AdvancedPerformanceDiagnostics` only when enabled and `name in advancedTimelineTimingNames`.
- `[DebugPerformanceReport.kt:DebugPerformanceReport]`: Fixes `SCHEMA_VERSION = 3`; `toPlainText()` omits empty `OFFLOAD EVENTS`, empty/disabled `ADVANCED DIAGNOSTICS`, and empty `NOTES`; `pcmEncodingLabel` maps Media3 PCM encoding constants (`2`, `3`, `4`, `21`, `22`, `536870912`) without importing Media3.
- `[DebugPerformanceReportCollector.kt:generate]`: Reads live player/decoder state on `Dispatchers.Main` before querying database/preferences on `Dispatchers.IO`, and classifies `setOf("flac", "alac", "wav", "aiff")` as lossless.

## Side Effects
- `[PerformanceMetrics.kt:PerformanceMetrics]` & `[AdvancedPerformanceDiagnostics.kt:AdvancedPerformanceDiagnostics]`: Mutate process-wide in-memory maps/deques/counters and read `System.currentTimeMillis()` / `SystemClock.elapsedRealtime()`; `trace`/`traceSuspend` emit Android systrace sections via `android.os.Trace`.
- `[AdvancedPerformanceDiagnosticsController.kt:start]`: Launches coroutines on the caller `CoroutineScope`, invokes `userPreferencesRepository.disableExpiredAdvancedPerformanceDiagnostics()`, and collects `advancedPerformanceDiagnosticsSettingsFlow`.
- `[MainThreadStallMonitor.kt:MainThreadStallMonitor]`: Registers and removes a `Choreographer.FrameCallback` on `Choreographer.getInstance()` and writes `FRAME_STALL` events into `AdvancedPerformanceDiagnostics`.
- `[DebugPerformanceReportCollector.kt:generate]`: Queries `MusicDao`, reads `UserPreferencesRepository` and `EqualizerPreferencesRepository`, queries `ActivityManager` (`Context.ACTIVITY_SERVICE`), and calls `AdvancedPerformanceDiagnostics.snapshot()` (which clears expired session state).
