# explore

## Overview
JioSaavn online discovery client, metadata/stream-URL mapping, ExoPlayer HTTP stream caching, and offline M4A + synced LRC track downloading for the Explore subsystem.

## Interface
- `[JioSaavnApiClient.kt:JioSaavnApiClient]`: `@Singleton` OkHttp + Gson API client exposing `globalSearch`, `searchSongs`, `searchAlbums`, `searchArtists`, `searchPlaylists`, `getTrendingSongs`, `getTrendingAlbums`, `getTrendingPlaylists`, `getSongById`, `getSongsByIds`, `getLyricsById`, `getSongSuggestions`, `getAlbumById`, `getPlaylistById`, and `getArtistById`, plus internal native feed loaders `getLaunchData` and `getNewReleases`.
- `[SaavnNativeAdapter.kt:SaavnNativeParser]`: Internal native `jiosaavn.com/api.php` JSON parser (`parseSongSearchResponse`, `parseTrendingSongs`, `parseAlbumsSearchResponse`, `parseTrendingAlbums`, `parseArtistsSearchResponse`, `parsePlaylistsSearchResponse`, `parseTrendingPlaylists`, `parseSongResponse`, `parseAlbumDetailResponse`, `parsePlaylistDetailResponse`, `parseArtistDetailResponse`, `parseLyricsResponse`, `parseLaunchData`, `parseNewReleases`) alongside `SaavnLaunchData`, `SaavnNewReleasesResult`, and internal helpers `isNativeSaavnApiUrl`, `decryptSaavnMediaUrl`, `buildDownloadUrlsFromDecrypted`, and `buildSaavnImages`.
- `[SaavnModels.kt]`: Wire DTOs (`SaavnImageDto`, `SaavnDownloadUrlDto`, `SaavnAlbumRefDto`, `SaavnArtistRefDto`, `SaavnArtistsGroupDto`, `SaavnLyricsDto`, `SaavnSongDto`, `SaavnSongResponse`, `SaavnLyricsResponse`, `SaavnSongSearchResponse`, `SaavnGlobalSearchResponse`, `SaavnAlbumSearchItemDto`, `SaavnAlbumsSearchResponse`, `SaavnAlbumDetailResponse`, `SaavnPlaylistsSearchResponse`, `SaavnPlaylistDetailResponse`, `SaavnArtistsSearchResponse`, `SaavnArtistDetailResponse`), domain UI models (`ExploreSong` with `selectStreamUrl`, `bestStreamUrl`, `toPlayerSong`; `ExploreAlbum`, `ExplorePlaylist`, `ExploreArtist`, `ExploreSearchResults`, `ExploreHomeFeed`), `SAAVN_SONG_ID_PREFIX` (`"saavn_"`), `Song.isExploreStream`, `Song.saavnId`, and `decodeSaavnHtml`.
- `[ExploreRepository.kt:ExploreRepository]`, `[ExploreRepository.kt:ExploreBrowseCategory]`: `@Singleton` repository exposing `clearFeedCache`, `getHomeFeed`, `searchAll`, `browseCategoryFeed`, `resolveSong`, `getAlbumDetail`, `getPlaylistDetail`, `getArtistDetail`, and `resolveArtistDetailForStream`.
- `[ExploreStreamCacheManager.kt:ExploreStreamCacheManager]`: `@Singleton` Media3 `SimpleCache` manager exposing `getCacheDirectory`, `createDataSourceFactory`, `pruneExpiredStreams`, `clearCache`, `measureCacheBytes`, and `countCachedEntries`.
- `[ExploreTrackDownloader.kt:ExploreTrackDownloader]`: `@Singleton` downloader exposing `downloads`, `downloadedSongIds`, `isDownloaded`, `enqueueSongDownload`, `enqueueBatchDownload`, `cancelDownload`, `retryDownload`, `removeDownloadEntry`, `clearCompleted`, and `Companion.sanitizeFilename`, alongside `ExploreDownloadStatus` and `ExploreDownloadItem`.

## Invariants
- `[JioSaavnApiClient.kt:JioSaavnApiClient]`: Runs all requests on `Dispatchers.IO`, routes `isNativeSaavnApiUrl(baseUrl)` requests to native `jiosaavn.com/api.php` endpoints parsed via `SaavnNativeParser` (sending Mumbai `geo` + language `L=<lang>` `Cookie` and `Referer` headers) and REST wrapper endpoints otherwise, normalizes URLs via `normalizeExploreApiBaseUrl`, validates HTTP URLs (`IllegalArgumentException` if invalid), falls back to `UserPreferencesRepository.FALLBACK_EXPLORE_API_BASE_URL` when a distinct primary fails, and throws `IllegalStateException` on non-2xx HTTP status or null parsed body.
- `[SaavnNativeAdapter.kt:decryptSaavnMediaUrl]`: Decrypts JioSaavn `encrypted_media_url` payloads using `DES/ECB/PKCS5Padding` (`"38346591"` key) and standard Base64, building `96`/`160`/`320` kbps AAC stream URLs in `buildDownloadUrlsFromDecrypted`.
- `[ExploreRepository.kt:ExploreRepository]`: Combines `webapi.getLaunchData`, `content.getAlbums`, `content.getTrending`, and `search.getArtistResults` on native endpoints (and search queries on REST mirrors) for `getHomeFeed` and `browseCategoryFeed`, normalizes `feedCache` keys with `language.lowercase().trim()`, caches home feeds only when at least one section is non-empty, short-circuits blank `searchAll` queries to empty results, drops songs with blank ID or decoded title, defaults unparseable bitrate qualities to `320` kbps, and rethrows the first error when all parallel sections in `getHomeFeed` or `searchAll` fail empty.
- `[SaavnModels.kt:ExploreSong]`, `[SaavnModels.kt:SAAVN_SONG_ID_PREFIX]`: Explore stream `Song.id` values use prefix `"saavn_"` (`SAAVN_SONG_ID_PREFIX`); `ExploreSong.selectStreamUrl` chooses exact `preferredKbps`, else closest bitrate by `abs(key - preferredKbps)`, else highest bitrate; `toPlayerSong` assigns negative hashed IDs for `artistId`/`albumId`/`ArtistRef.id`, marks index `0` artist `isPrimary = true`, and sets `mimeType = "audio/mp4"` and `sampleRate = 44100`.
- `[ExploreStreamCacheManager.kt:ExploreStreamCacheManager]`: Synchronizes `SimpleCache` lifecycle on `cacheLock` (default `250` MB, disabled when `limitMb <= 0`, LRU eviction via `LeastRecentlyUsedCacheEvictor`); `SelectiveHttpCacheDataSource` caches only `http`/`https` URIs with `FLAG_IGNORE_CACHE_ON_ERROR`; `measureCacheBytes` excludes `.uid`, `db`, `db-wal`, and `db-shm` files.
- `[ExploreTrackDownloader.kt:ExploreTrackDownloader]`: On startup reconciles persisted `QUEUED`/`DOWNLOADING` entries to `FAILED` (`"Interrupted when app closed"`) and prunes missing `COMPLETED` outputs; deduplicates active downloads by `song.id`; resolves lyrics in priority order LRCLIB `getLyrics` (synced) -> `searchLyrics(track, artist)` (synced) -> `searchLyrics(query)` (synced) -> plain LRCLIB -> `song.lyricsText`; embeds reverse-DNS MP4 atom `----:<packageName>:TrackUID`; persists snapshots atomically via `explore_downloads.json.tmp` -> `explore_downloads.json` under `persistLock`; and `sanitizeFilename` strips `[\\/:*?"<>|]` (falling back to `"Track"`).

## Side Effects
- `[JioSaavnApiClient.kt:JioSaavnApiClient]`: Executes synchronous OkHttp GET requests on `Dispatchers.IO`.
- `[ExploreRepository.kt:ExploreRepository]`: Mutates in-memory `ConcurrentHashMap` `feedCache` and reads `userPreferencesRepository.exploreApiBaseUrlFlow`.
- `[ExploreStreamCacheManager.kt:ExploreStreamCacheManager]`: Launches an IO coroutine on a `SupervisorJob` collecting `exploreStreamCacheLimitMbFlow` and `exploreStreamCacheAutoCleanDaysFlow`, creates/prunes/deletes files and SQLite index DBs in `context.cacheDir/explore_stream_cache`, and logs via `Timber`.
- `[ExploreTrackDownloader.kt:ExploreTrackDownloader]`: Scans `Music/MusicLi` on startup, downloads audio/artwork over OkHttp, queries `ExploreRepository` and `LrcLibApiService`, writes/deletes temp files in `context.cacheDir`, embeds MP4 tags via JAudioTagger, writes `.m4a` and `.lrc` outputs to SAF (`DocumentsContract`), MediaStore (`Audio.Media` / `Files`), or `Music/PixelPlayerOSS`, inserts lyrics into `LyricsDao`, triggers `MediaScannerConnection.scanFile`, enqueues `SyncWorker.incrementalSyncWork()` via `WorkManager`, posts download notifications on channel `"explore_downloads_channel"`, and persists `context.filesDir/explore_downloads.json`.
