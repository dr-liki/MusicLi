# Repository

## Overview
Provides the primary media, lyrics, artist-artwork, folder-tree, transition-rule, and audio-bookmark repository interfaces and implementations under `com.drliki.MusicLi.data.repository`.

## Interface
- `[MusicRepository.kt:MusicRepository]` & `[MusicRepositoryImpl.kt:MusicRepositoryImpl]` — Unified library repository (`@Singleton`) exposing paginated/non-paginated `Song`, `Album`, `Artist`, `Playlist`, `Genre`, `MusicFolder`, favorite, search, search-history, and lyrics-delegated APIs (`getAudioFiles`, `getPaginatedSongs`, `getPaginatedAlbums`, `getPaginatedArtists`, `getPaginatedFavoriteSongs`, `getFavoriteSongsOnce`, `getFavoriteSongsPage`, `getFavoriteSongCountFlow`, `getSongCountFlow`, `getCloudSongCountFlow`, `getRandomSongs`, `getSongsPage`, `getAlbumsPage`, `getArtistsPage`, `getFirstPlayableSong`, `getAlbums`, `getAlbumById`, `getArtists`, `getSongsForAlbum`, `getArtistById`, `getArtistIdByName`, `getArtistsForSong`, `getSongsForArtist`, `getAllUniqueAudioDirectories`, `getAllUniqueAlbumArtUris`, `searchSongs`, `searchAlbums`, `searchArtists`, `searchPlaylists`, `searchAll`, `addSearchHistoryItem`, `getRecentSearchHistory`, `deleteSearchHistoryItemByQuery`, `clearSearchHistory`, `getMusicByGenre`, `getSongsByIds`, `getSongByPath`, `invalidateCachesDependentOnAllowedDirectories`, `getAllSongsOnce`, `getSongsByIdsOnce`, `getDistinctAlbumArtSongs`, `getHomeMixPreviewSongs`, `getAllAlbumsOnce`, `getAllArtistsOnce`, `setFavoriteStatus`, `getFavoriteSongIdsOnce`, `getFavoriteSongIdsFlow`, `toggleFavoriteStatus`, `getSong`, `getGenres`, `getLyrics`, `getStoredLyrics`, `getLyricsFromRemote`, `searchRemoteLyrics`, `searchRemoteLyricsByQuery`, `updateLyrics`, `resetLyrics`, `resetAllLyrics`, `getMusicFolders`, `deleteById`, `getSongIdsSorted`, `getFavoriteSongIdsSorted`, `getSongIdByContentUri`), plus `[MusicRepositoryImpl.kt:CachedDirFilter]`.
- `[SongRepository.kt:SongRepository]` & `[MediaStoreSongRepository.kt:MediaStoreSongRepository]` — MediaStore/Room song data source (`getSongs`, `getSongsByAlbum`, `getSongsByArtist`, `searchSongs`, `getSongById`, `getPaginatedSongs`, `getPaginatedFavoriteSongs`, `getFavoriteSongsOnce`, `getFavoriteSongCountFlow`).
- `[LyricsRepository.kt:LyricsRepository]` & `[LyricsRepositoryImpl.kt:LyricsRepositoryImpl]` — `@Singleton` lyrics pipeline (`getStoredLyrics`, `getLyrics`, `fetchFromRemote`, `searchRemote`, `searchRemoteByQuery`, `updateLyrics`, `resetLyrics`, `resetAllLyrics`, `clearCache`, `scanAndAssignLocalLrcFiles`), DTOs/exceptions (`[LyricsRepositoryImpl.kt:LyricsSearchResult]`, `[LyricsRepositoryImpl.kt:NoLyricsFoundException]`, `[LyricsRepositoryImpl.kt:LyricsException]`), and internal helpers (`containsReplacementCharacter`, `parseBestEmbeddedLyricsField`).
- `[ArtistImageRepository.kt:ArtistImageRepository]` — `@Singleton` artist artwork resolver (`folderArtworkRevision`, `getArtistImageUrl`, `prefetchArtistImages`, `clearCache`, `getFolderArtistImageUrl`, `getEffectiveArtistImageUrl`, `setCustomArtistImage`, `clearCustomArtistImage`, internal `Companion.calculateCustomImageSampleSize`).
- `[FolderTreeBuilder.kt:FolderTreeBuilder]` — `@Singleton` hierarchical `MusicFolder` tree builder (`buildFolderTree`, internal `buildFolderTreeForRoots`, `inferRemovableStorageRoots`).
- `[AudioBookmarkRepository.kt:AudioBookmarkRepository]` & `[AudioBookmarkRepositoryImpl.kt:AudioBookmarkRepositoryImpl]` — `@Singleton` audio bookmark CRUD and backup relinking (`getAllBookmarksFlow`, `getBookmarksForSong`, `insertBookmark`, `deleteBookmark`, `deleteBookmarks`, `getBookmarkById`, `relinkOrphanedBookmarks`).
- `[TransitionRepository.kt:TransitionRepository]` & `[TransitionRepositoryImpl.kt:TransitionRepositoryImpl]` — `@Singleton` crossfade/transition rule resolver (`resolveTransitionSettings`, `getAllRulesForPlaylist`, `getPlaylistDefaultRule`, `saveRule`, `deleteRule`, `deletePlaylistDefaultRule`, `getGlobalSettings`, `saveGlobalSettings`).

## Invariants
- `[MusicRepositoryImpl.kt:MusicRepositoryImpl]` bounds search results to `SEARCH_RESULTS_LIMIT = 100`, lyric search batches to `32`, SQL `IN` song-ID batches to `SONGS_BY_ID_BATCH_SIZE = 900` (under SQLite's `999` limit), and `PagingConfig` to `pageSize = 50, enablePlaceholders = true, maxSize = 250`.
- `[MusicRepositoryImpl.kt:MusicRepositoryImpl.cachedDirFilter]` short-circuits directory observation when `blockedDirectoriesFlow` is empty; `[MusicRepositoryImpl.kt:MusicRepositoryImpl.getSongsByIdsOnce]` passes cloud songs (`id < 0`) regardless of directory rules; `[MusicRepositoryImpl.kt:MusicRepositoryImpl.setFavoriteStatus]` serializes Jellyfin favorite toggles under `withLocalFavoriteLock`.
- `[MusicRepositoryImpl.kt:MusicRepositoryImpl.getAllUniqueAudioDirectories]` serializes MediaStore scans under `directoryScanMutex` and accepts `IS_MUSIC != 0` or `.m4a`/`.flac` files; `[MusicRepositoryImpl.kt:MusicRepositoryImpl.searchSongs]` and sibling search methods short-circuit on blank queries.
- `[MediaStoreSongRepository.kt:MediaStoreSongRepository]` enforces `minDurationMs` (default `10000` ms) and `DirectoryRuleResolver` parent-path blocking when `blockedDirs` is non-empty, deduplicates title-extracted artists case-insensitively with synthetic negative secondary IDs, and forces `isFavorite = true` on favorite queries.
- `[LyricsRepositoryImpl.kt:LyricsRepositoryImpl]` caps `lyricsCache` at `150` entries, enforces `MAX_CALLS_PER_MINUTE = 30` and `100ms`/`250ms` inter-call rate limits with `3`-attempt retry on `IOException`/`429`/`>= 500`, honors `LyricsSourcePreference` (`API_FIRST`, `EMBEDDED_FIRST`, `LOCAL_FIRST`), defers `U+FFFD`-damaged entries, rejects `http://`/`https://` in `loadEmbeddedLyricsFromMetadata`, requires `Lyrics.isValid()` on updates/saves, and skips remote calls when `!isExternalLyricsEnabled()`.
- `[LyricsRepositoryImpl.kt:LyricsRepositoryImpl.rankRemoteLyricsMatches]` requires positive song/response durations, compatible `variantDescriptorsCompatible` timing markers, mode-bounded duration tolerance (`AUTOMATIC` synced `[5.0, 8.0]s`, unsynced `[8.0, 15.0]s`, `CANDIDATE` `15.0s`), and title/artist token overlap thresholds; `[LyricsRepositoryImpl.kt:LyricsRepositoryImpl.scanAndAssignLocalLrcFiles]` chunks DB lookups by `900` and bounds file scans with `Semaphore(8)`.
- `[ArtistImageRepository.kt:ArtistImageRepository]` checks custom DB image -> folder artist image -> memory cache (`100`) -> Room DB -> Deezer API; deduplicates concurrent fetches via `fetchMutex`/`pendingFetches`, bounds prefetching with `Semaphore(3)` in chunks of `12`, caps folder directory queries at `64`, and rejects custom images `> 24 MiB`, `> 16384 px`, or `> 80M` pixels (decoding to `<= 2048 px` `RGB_565`).
- `[AudioBookmarkRepositoryImpl.kt:AudioBookmarkRepositoryImpl]` chunks `deleteBookmarks` in batches of `500` and relinks orphaned bookmarks only on ID resolution or unique title+artist match.
- `[FolderTreeBuilder.kt:FolderTreeBuilder]` strips descendant/ancestor root overlaps, excludes blocked directories when `isFolderFilterActive && blockedDirs.isNotEmpty()`, sorts folders by lowercase name and songs by positive `trackNumber` then title, and maps volatile artwork URIs to `LocalArtworkUri.buildSongUri(id)`.
- `[TransitionRepositoryImpl.kt:TransitionRepositoryImpl.resolveTransitionSettings]` resolves `PLAYLIST_SPECIFIC` -> `PLAYLIST_DEFAULT` -> `GLOBAL_DEFAULT`.

## Side Effects
- `[MusicRepositoryImpl.kt:MusicRepositoryImpl]` collects `cachedDirFilter` on `repositoryScope`, reads/mutates Room (`MusicDao`, `FavoritesDao`, `SearchHistoryDao`), queries `MediaStore`, triggers `artistImageRepository.prefetchArtistImages`, pushes Jellyfin favorite changes remotely, and delegates lyrics operations.
- `[MediaStoreSongRepository.kt:MediaStoreSongRepository]` queries `MediaStore.Audio.Media` and `MediaStore.Audio.Genres`, observes `MediaStoreObserver`, and reads `FavoritesDao`/`MusicDao`/`UserPreferencesRepository`.
- `[LyricsRepositoryImpl.kt:LyricsRepositoryImpl]` reads/writes `LyricsDao`, `filesDir/lyrics/*.json`, temp files in `cacheDir`, `lyricsCache`, and local `.lrc`/embedded audio tags, and calls LRCLIB / `MultiProviderLyricsOrchestrator` over HTTPS.
- `[ArtistImageRepository.kt:ArtistImageRepository]` queries Deezer API, reads/writes `MusicDao`, writes/deletes `filesDir/artist_art_<id>.jpg`, reads `ContentResolver` image streams, and updates `folderArtworkRevision`.
- `[AudioBookmarkRepositoryImpl.kt:AudioBookmarkRepositoryImpl]` reads/writes Room `AudioBookmarkDao`; `[FolderTreeBuilder.kt:FolderTreeBuilder]` reads storage volume state via `StorageUtils` and `Environment`; `[TransitionRepositoryImpl.kt:TransitionRepositoryImpl]` reads/writes `TransitionDao` and `UserPreferencesRepository`.
