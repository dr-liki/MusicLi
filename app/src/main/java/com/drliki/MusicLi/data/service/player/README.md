# Service Player

## Overview
Implements the dual-ExoPlayer playback engine, crossfade/transition controller, Hi-Fi/USB bit-perfect audio output pipeline, PCM processors, and Media3 `ForwardingPlayer` wrappers under `com.drliki.MusicLi.data.service.player`.

## Interface
- `[DualPlayerEngine.kt:DualPlayerEngine]` — `@Singleton` dual-ExoPlayer engine managing master/auxiliary player instances, audio focus, Bluetooth/session offload fallback, wake modes, cloud URI resolution, windowed queue splicing, and overlap transitions (`masterPlayer`, `audioOutputMode`, `sleepTimerHold`, `activeAudioSessionId`, `activeDecoderInfo`, `isAudioOffloadEnabled`, `incomingTrackReplayGainVolume`, `initialize`, `release`, `setAudioOutputMode`, `setPreferredAudioDevice`, `setPauseAtEndOfMediaItems`, `setSleepTimerHold`, `getNextTransitionTarget`, `resolveCloudUri`, `resolveMediaItem`, `prepareNext`, `cancelNext`, `performTransition`, `getFullQueue`, `getCurrentAbsoluteIndex`, `triggerAdjacentPreResolution`, `currentAudioFormatSnapshot`, `clearResolvedUriCache`, `notifyExternalSeekInitiated`, and swap/display/finished/end-pause listener registration).
- `[DualPlayerEngine.kt:ActiveDecoderInfo]`, `[DualPlayerEngine.kt:DualPlayerEngine.TransitionTarget]`, `[DualPlayerEngine.kt:DualPlayerEngine.SleepTimerHold]`, `[DualPlayerEngine.kt:DualPlayerEngine.AudioFormatSnapshot]` — Public engine state/telemetry models; `[DualPlayerEngine.kt:TransitionRunTracker]`, `[DualPlayerEngine.kt:PlayerRebuildQueueWindow]`, and internal policy helpers (`shouldUsePresentedAuxiliaryForPlayerRebuild`, `selectPlayerRebuildQueueWindow`, `shouldResumeAfterTransientAudioFocusLoss`, `shouldDisableAudioOffloadByDefaultForDevice`, `isAudioOffloadMarkedBroken`, `shouldEnableAudioOffloadForMode`, `isBluetoothAudioDeviceType`, `shouldTriggerAudioOffloadStallFallback`, `shouldDisableAudioOffloadOnEarlyBuffering`).
- `[TransitionController.kt:TransitionController]` — `@Singleton` orchestrator observing playback items, `TransitionRepository`, `UserPreferencesRepository`, `TrackBpmRepository`, and `DualPlayerEngine.sleepTimerHold` to schedule and execute manual or smart crossfades (`initialize`, `release`).
- `[SmartCrossfadePlanner.kt:SmartCrossfadePlanner]`, `[SmartCrossfadePlanner.kt:SmartCrossfadePlan]`, `[SmartCrossfadePlanner.kt:BpmCompatibility]` — Pure BPM-aware crossfade planner (`foldedTempoRatio`, `compatibility`, `plan`).
- `[QueueWindowPolicy.kt:QueueWindowPolicy]`, `[QueueWindowPolicy.kt:QueueWindowPolicy.RestorePlan]` — Internal auxiliary-player queue windowing (`MAX_AUXILIARY_TIMELINE_ITEMS = 200`, `windowBounds`, `restorePlan`).
- `[BitPerfectUsbAudioOutputProvider.kt:BitPerfectUsbAudioOutputProvider]`, `[BitPerfectUsbAudioOutputProvider.kt:BitPerfectUsbStatus]`, `[BitPerfectUsbAudioOutputProvider.kt:MixerFormat]`, `[BitPerfectUsbAudioOutputProvider.kt:selectBitPerfectMixerFormat]` — Android 14+ (`UPSIDE_DOWN_CAKE`) `AudioOutputProvider` configuring USB DAC preferred mixer attributes (`activeStatus` `StateFlow`).
- `[PcmWideningAudioOutput.kt:PcmWideningAudioOutput]` — Internal `AudioOutput` wrapper widening `PCM_16BIT` or `PCM_FLOAT` to `PCM_24BIT` or `PCM_32BIT` (`bytesPerSample`, `write`, `flush`, `release`, `canReuseAudioOutput`).
- `[HiFiCapabilityChecker.kt:HiFiCapabilityChecker]` — Hardware `PCM_FLOAT` `AudioTrack` capability probe (`isSupported`).
- `[HiResSampleRateCapAudioProcessor.kt:HiResSampleRateCapAudioProcessor]` — `AudioProcessor` capping ultra-high PCM sample rates to `maxOutputSampleRateHz` (default `192_000` Hz) via integer downsampling.
- `[SurroundDownmixProcessor.kt:SurroundDownmixProcessor]` — `AudioProcessor` downmixing 6-channel (5.1) and 8-channel (7.1) `PCM_16BIT`/`PCM_FLOAT` streams to stereo.
- `[AudioDecoderPolicy.kt:AudioDecoderPolicy]` — Internal codec policy (`hasUnsupportedAudio`, `shouldUseExtensionRenderer`, `selectPlatformDecoders`, `isLikelyHardwareDecoder`).
- `[UnsupportedAudioListener.kt:UnsupportedAudioListener]` — Internal `Player.Listener` pausing and reporting tracks with no decodable audio.
- `[FadingPlayer.kt:FadingPlayer]` — `ForwardingPlayer` applying smooth `500L` ms (`25` steps) play/pause volume fades while reporting logical `playWhenReady`/`isPlaying`/`volume`.
- `[MappingPlayer.kt:MappingPlayer]` — `ForwardingPlayer` rewriting outgoing `MediaItem`/`MediaMetadata`/`Timeline` artwork URIs via `MediaItemBuilder.externalControllerArtworkUri` and publishing them to `SharedArtworkContentProvider`.
- `[PreviousButtonPlayer.kt:PreviousButtonPlayer]` — `ForwardingPlayer` routing `seekToPrevious()` based on `PreviousButtonBehavior`.
- `[CloudPlaybackUriResolver.kt:resolvePreferredCloudPlaybackValue]`, `[CloudPlaybackUriResolver.kt:selectCanonicalCloudPlaybackUri]`, `[CloudPlaybackUriResolver.kt:isCanonicalCloudPlaybackUri]` — Internal cloud URI precedence (`offline > cached > remote > original`) and `navidrome`/`jellyfin` canonical URI checks.

## Invariants
- `[DualPlayerEngine.kt:DualPlayerEngine.buildPlayer]` wraps every audio sink in `EqualizerAudioSink`, uses `BitPerfectUsbAudioOutputProvider` only on `AudioOutputMode.BIT_PERFECT_USB` at API >= 34, pins `sharedAudioSessionId` only when `!outputMode.usesUnmodifiedMedia3AudioSink`, and rejects unresolved `CLOUD_PROXY_SCHEMES` (`navidrome`, `jellyfin`) in `ResolvingDataSource.Resolver` by throwing `IOException`.
- `[DualPlayerEngine.kt:DualPlayerEngine.applyAudioOffloadPreferences]` requires `isGaplessSupportRequired(true)`; `[DualPlayerEngine.kt:shouldEnableAudioOffloadForMode]` enables offload only for `AudioOutputMode.SYSTEM_DEFAULT` when offload is available, audio effects are disabled, and Bluetooth audio output is inactive; `[DualPlayerEngine.kt:shouldDisableAudioOffloadByDefaultForDevice]` disables offload by default on Xiaomi/Redmi/POCO (`sdkInt >= 36`), Google/Pixel (`sdkInt >= 37`), and Lava/MediaTek (`sdkInt >= 35`).
- `[DualPlayerEngine.kt:DualPlayerEngine.performOverlapTransition]` aborts and restores pre-transition volume and `pauseAtEndOfMediaItems` if `playerB` is null/empty or `awaitPlayerReady(auxiliaryPlayer, 3000L)` returns `false`; transition duration is clamped `>= 500ms`; `[DualPlayerEngine.kt:TransitionRunTracker]` prevents stale transition coroutines from mutating state after cancellation/supersession.
- `[DualPlayerEngine.kt:DualPlayerEngine.restoreFullMasterTimelineIfWindowed]` splices the full queue onto `playerA` only when `QueueWindowPolicy.restorePlan` is non-null and `windowMatchesSnapshot` confirms boundary media IDs match.
- `[DualPlayerEngine.kt:DualPlayerEngine.applyOffloadAwareWakeMode]` drops wake mode to `C.WAKE_MODE_NONE` only when sleeping for offload on local media with `!_sleepTimerHold.value.keepCpuAwake`.
- `[TransitionController.kt:TransitionController.scheduleTransitionFor]` suppresses crossfades when `sleepTimerHold.suppressCrossfade` is true or track duration `< 650 ms` (`minFade = 500L`, `guardWindow = 150L`), skips smart crossfade for `TransitionSource.PLAYLIST_SPECIFIC`, and applies playlist-specific pair rules only when both tracks share a non-null `playlistId`.
- `[SmartCrossfadePlanner.kt:SmartCrossfadePlanner.plan]` returns `null` unless `compatibility` is `ALIGNED` (`<= 0.04f`) or `COMPATIBLE` (`<= 0.10f`) and `trackDurationMs >= minFadeMs + guardWindowMs`; quantizes fade to whole 4-beat bars clamped to `[minFadeMs, min(base.durationMs * 2.0f, 12_000L, trackDurationMs - guardWindowMs)]` using `Curve.S_CURVE`.
- `[BitPerfectUsbAudioOutputProvider.kt:BitPerfectUsbAudioOutputProvider.planBitPerfectOutput]` bypasses bit-perfect routing for offload, tunneling, non-`AUDIO_RAW`, or non-USB outputs, caps plan cache at `MAX_PLANS` (`8`), and guards mixer clearing on `currentOwner === this`.
- `[PcmWideningAudioOutput.kt:PcmWideningAudioOutput]` accepts only `PCM_16BIT`/`PCM_FLOAT` inputs widened to `PCM_24BIT`/`PCM_32BIT` in native byte order, clamping 24-bit samples to `[-8_388_608L, 8_388_607L]` and 32-bit samples to `[Int.MIN_VALUE, Int.MAX_VALUE]`.
- `[HiResSampleRateCapAudioProcessor.kt:HiResSampleRateCapAudioProcessor]` activates only for `PCM_16BIT`/`PCM_FLOAT` with `sampleRate > maxOutputSampleRateHz`; `[SurroundDownmixProcessor.kt:SurroundDownmixProcessor]` activates only for 6- or 8-channel `PCM_16BIT`/`PCM_FLOAT` using `0.707f` surround/LFE coefficients.
- `[AudioDecoderPolicy.kt:AudioDecoderPolicy.shouldUseExtensionRenderer]` forces extension decoders for ALAC, MIDI, and FLAC when `outputMode.usesFloatOutput` is `true`.
- `[FadingPlayer.kt:FadingPlayer]` reports `getPlayWhenReady() == false` and `isPlaying() == false` during `isFadingToPause` and cancels an active pause fade on `setPlayWhenReady(true)`.

## Side Effects
- `[DualPlayerEngine.kt:DualPlayerEngine]` creates/releases `ExoPlayer` instances, allocates a shared audio session ID, requests/abandons `AudioManager` focus, registers/unregisters Bluetooth `AudioDeviceCallback`, mutates wake modes, reads/writes `"audio_offload_health"` `SharedPreferences`, resolves cloud URIs via `cloudOfflineRepository` and stream proxies on `Dispatchers.IO`, and dispatches swap/display/finished/end-pause callbacks and `StateFlow` updates.
- `[TransitionController.kt:TransitionController]` attaches `Player.Listener` and swap listeners, polls player position via coroutines on `Dispatchers.Main`, mutates `DualPlayerEngine` (`setPauseAtEndOfMediaItems`, `prepareNext`, `cancelNext`, `performTransition`), and logs via `Timber`.
- `[BitPerfectUsbAudioOutputProvider.kt:BitPerfectUsbAudioOutputProvider]` calls `AudioManager.setPreferredMixerAttributes`/`clearPreferredMixerAttributes` and updates `Companion.activeStatus`.
- `[HiFiCapabilityChecker.kt:HiFiCapabilityChecker.runCheck]` allocates and releases a probe `AudioTrack` on first check and caches the result in `@Volatile cachedResult`.
- `[PcmWideningAudioOutput.kt:PcmWideningAudioOutput]`, `[HiResSampleRateCapAudioProcessor.kt:HiResSampleRateCapAudioProcessor]`, and `[SurroundDownmixProcessor.kt:SurroundDownmixProcessor]` allocate direct `ByteBuffer`s and transform PCM frames.
- `[FadingPlayer.kt:FadingPlayer]` launches `Dispatchers.Main` fade coroutines, mutates `innerPlayer` play/pause/volume, and notifies `Player.Listener`s.
- `[MappingPlayer.kt:MappingPlayer]` calls `SharedArtworkContentProvider.publishSessionArtwork(...)` when exposing artwork URIs.
- `[PreviousButtonPlayer.kt:PreviousButtonPlayer]` calls `seekToPreviousMediaItem()` or `super.seekToPrevious()` on `innerPlayer`.
- `[UnsupportedAudioListener.kt:UnsupportedAudioListener]` calls `player.pause()` and emits `onUnsupported(mimeType)`.
