# database

## Overview
Room persistence layer (`PixelPlayerDatabase`) defining all 21 SQLite tables, FTS4 full-text search index, runtime SQLite triggers, schema migrations (`1` -> `7`), 14 DAOs, and entity-to-domain mappers for local library metadata, playlists, engagement/favorites, lyrics, transitions, cloud caches, offline downloads, bookmarks, synced videos, and pending ListenBrainz scrobbles.

## Interface
- `[PixelPlayerDatabase.kt:PixelPlayerDatabase]`: `@Database(version = 7, exportSchema = true)` exposing 14 DAOs (`albumArtThemeDao`, `searchHistoryDao`, `musicDao`, `transitionDao`, `engagementDao`, `favoritesDao`, `lyricsDao`, `localPlaylistDao`, `navidromeDao`, `jellyfinDao`, `listenBrainzDao`, `audioBookmarkDao`, `offlineTrackDao`, `syncedVideoDao`) and companion helpers `installFavoriteSyncTriggers`, `installSongsSearchSyncTriggers`, `createRuntimeArtifactsCallback`.
- `[Migrations.kt:MIGRATION_1_2]`, `[Migrations.kt:MIGRATION_2_3]`, `[Migrations.kt:MIGRATION_3_4]`, `[Migrations.kt:MIGRATION_4_5]`, `[Migrations.kt:MIGRATION_5_6]`, `[Migrations.kt:MIGRATION_6_7]`: Incremental Room `Migration` objects covering schema versions `1` through `7`.
- `[MusicDao.kt:MusicDao]`: Core library DAO for `songs`, `albums`, `artists`, and `song_artist_cross_ref` (upserts, chunked incremental sync, directory/source-filtered queries, Paging3 `PagingSource`, FTS4 + LIKE search, genre/library stats, artwork/custom artist images, MusicBrainz matching, and favorites/lyrics helpers), alongside row DTOs `DeviceCapabilitySongRow`, `SongLyricSearchRow`, `LocalAlbumGroupingSource`, `LibraryAudioStatsRow`, `MimeTypeCountRow`, `GenreSongCountRow`, `SongIdUriMapping`, and constants `SONG_BATCH_SIZE` (`500`), `CROSS_REF_BATCH_SIZE` (`333`).
- `[SongEntity.kt:SongEntity]`, `[SongEntity.kt:SourceType]`, `[SongEntity.kt:SongSummary]`, `[SongSearchFtsEntity.kt:SongSearchFtsEntity]`, `[FolderSongRow.kt:FolderSongRow]`: `songs` table (`SourceType.LOCAL = 0`, `NAVIDROME = 5`, `JELLYFIN = 6`), FTS4 virtual table `songs_fts`, folder projection row, and mappers (`toSong`, `toSongs`, `toSongWithArtistRefs`, `serializeArtistRefs`, `toEntity`, `toEntityWithoutPaths`).
- `[AlbumEntity.kt:AlbumEntity]` & `[ArtistEntity.kt:ArtistEntity]`: `albums` (`toAlbum`, `toAlbums`, `toEntity`) and `artists` (`toArtist`, `toArtists`, `toEntity`) tables and mappers.
- `[SongArtistCrossRef.kt:SongArtistCrossRef]`: `song_artist_cross_ref` join table with relation models `SongWithArtists`, `ArtistWithSongs`, and `PrimaryArtistInfo`.
- `[LocalPlaylistDao.kt:LocalPlaylistDao]`, `[PlaylistEntity.kt:PlaylistEntity]`, `[PlaylistSongEntity.kt:PlaylistSongEntity]`, `[PlaylistWithSongsEntity.kt:PlaylistWithSongsEntity]`: `playlists` and `playlist_songs` tables, relation model, and mappers (`toPlaylist`, `toEntity`).
- `[FavoritesDao.kt:FavoritesDao]` & `[FavoritesEntity.kt:FavoritesEntity]`: `favorites` table and reactive/batch accessors.
- `[EngagementDao.kt:EngagementDao]` & `[SongEngagementEntity.kt:SongEngagementEntity]`: `song_engagements` table and atomic `recordPlay` / ranking queries.
- `[LyricsDao.kt:LyricsDao]` & `[LyricsEntity.kt:LyricsEntity]`: `lyrics` table for cached/imported lyrics.
- `[TransitionDao.kt:TransitionDao]` & `[TransitionRuleEntity.kt:TransitionRuleEntity]`: `transition_rules` table for playlist default and track-pair transition rules.
- `[AudioBookmarkDao.kt:AudioBookmarkDao]` & `[AudioBookmarkEntity.kt:AudioBookmarkEntity]`: `audio_bookmarks` table and placeholder helpers (`restoredBookmarkSongId`, `backupSongIdOfRestoredBookmark`).
- `[SearchHistoryDao.kt:SearchHistoryDao]` & `[SearchHistoryEntity.kt:SearchHistoryEntity]`: `search_history` table and mappers (`toSearchHistoryItem`, `toEntity`).
- `[SyncedVideoDao.kt:SyncedVideoDao]` & `[SyncedVideoEntity.kt:SyncedVideoEntity]`: `synced_videos` table mapping song keys to YouTube video IDs.
- `[AlbumArtThemeDao.kt:AlbumArtThemeDao]`, `[AlbumArtThemeEntity.kt:AlbumArtThemeEntity]`, `[ColorConverters.kt:toComposeColor]`: `album_art_themes` table (`StoredColorSchemeValues` light/dark embedded palettes) and Compose `String.toComposeColor()` parser.
- `[NavidromeDao.kt:NavidromeDao]`, `[NavidromePlaylistEntity.kt:NavidromePlaylistEntity]`, `[NavidromeSongEntity.kt:NavidromeSongEntity]`: `navidrome_playlists` and `navidrome_songs` tables (`toSong`, `toEntity`).
- `[JellyfinDao.kt:JellyfinDao]`, `[JellyfinPlaylistEntity.kt:JellyfinPlaylistEntity]`, `[JellyfinSongEntity.kt:JellyfinSongEntity]`: `jellyfin_playlists` and `jellyfin_songs` tables (`toSong`, `toEntity`).
- `[OfflineTrackDao.kt:OfflineTrackDao]` & `[OfflineTrackEntity.kt:OfflineTrackEntity]`: `offline_tracks` table tracking download attempts and completion state.
- `[ListenBrainzDao.kt:ListenBrainzDao]` & `[ListenBrainzPendingListenEntity.kt:ListenBrainzPendingListenEntity]`: `listenbrainz_pending_listens` queue table and `ListenBrainzSource` (`LOCAL`, `NAVIDROME`, `JELLYFIN`, `fromSourceType`).

## Invariants
- `[PixelPlayerDatabase.kt:PixelPlayerDatabase]`: Database version is `7` (`exportSchema = true`, no `@TypeConverters`); `installFavoriteSyncTriggers` keeps `songs.is_favorite` synchronized with `favorites` (`INSERT`/`UPDATE`/`DELETE`), and `installSongsSearchSyncTriggers` keeps FTS4 `songs_fts` (`tokenize=unicode61`, `rowid = songs.id`) synchronized with `songs`.
- `[Migrations.kt:MIGRATION_1_2]`, `[Migrations.kt:MIGRATION_2_3]`, `[Migrations.kt:MIGRATION_5_6]`: `MIGRATION_1_2` and `MIGRATION_2_3` probe `PRAGMA table_info` before `ALTER TABLE ADD COLUMN` to tolerate Auto Backup schema drift; `MIGRATION_5_6` rewrites `playlist_songs` primary key from `(playlist_id, song_id)` to `(playlist_id, sort_order)` with dense 0-based `ROW_NUMBER()` ordering so duplicate tracks per playlist are preserved.
- `[SongEntity.kt:SongEntity]` & `[SongArtistCrossRef.kt:SongArtistCrossRef]`: `songs.album_id` cascades delete from `albums(id)`, `songs.artist_id` uses `ForeignKey.SET_NULL` from `artists(id)`, and `song_artist_cross_ref` cascades delete from both `songs(id)` and `artists(id)`.
- `[MusicDao.kt:MusicDao]`: Inserts `artists` -> `albums` -> `songs` -> `song_artist_cross_ref` in dependency order; chunks `SongArtistCrossRef` operations at `CROSS_REF_BATCH_SIZE` (`333`) and song batches at `SONG_BATCH_SIZE` (`500`); preserves existing artist `image_url`/`custom_image_uri` on conflict; exempts negative-ID songs (`id < 0`) from directory filters; keeps `deleteOrphanedArtists` safe against `songs.artist_id` / `songs.album_artist_id` references; and prioritizes `songs_fts` `MATCH` hits over `LIKE` hits in `searchSongs` / `searchSongsLimited`.
- `[OfflineTrackDao.kt:OfflineTrackDao]` & `[OfflineTrackEntity.kt:OfflineTrackEntity]`: `source_uri` is uniquely indexed; `updateState` and `deleteBySourceUriForAttempt` gate mutations on matching `attempt_id` so stale workers cannot overwrite newer download attempts.
- `[NavidromeDao.kt:NavidromeDao]` & `[JellyfinDao.kt:JellyfinDao]`: Library-wide cloud songs use `playlist_id = '__library__'` with primary key `"${playlistId}_$id"`, and `replaceLibrarySongs` atomically clears and reinserts `'__library__'` rows inside `@Transaction`.
- `[PlaylistSongEntity.kt:PlaylistSongEntity]` & `[LocalPlaylistDao.kt:LocalPlaylistDao]`: Composite PK `(playlist_id, sort_order)` enforces unique 0-based positions; `replaceSongsOfExistingPlaylist` returns `false` without inserting if `getPlaylistById(playlistId)` is `null`.
- `[TransitionRuleEntity.kt:TransitionRuleEntity]` & `[TransitionDao.kt:TransitionDao]`: Unique index on `(playlistId, fromTrackId, toTrackId)`; playlist defaults have `fromTrackId IS NULL AND toTrackId IS NULL` and are excluded by `deleteRulesForTrack`.
- `[AudioBookmarkEntity.kt:restoredBookmarkSongId]`: Unresolved restored local bookmarks use the `"restored:"` `songId` prefix to prevent collisions with MediaStore IDs.
- `[AlbumArtThemeEntity.kt:AlbumArtThemeEntity]`: `@PrimaryKey` on `albumArtUriString` allows at most one cached theme row per artwork URI.
- `[ColorConverters.kt:toComposeColor]`: Invalid color strings catch `IllegalArgumentException` and fall back to `Color.Black`.

## Side Effects
- `[PixelPlayerDatabase.kt:createRuntimeArtifactsCallback]`: Executes DDL on SQLite during `RoomDatabase.Callback.onCreate` to create `songs_fts` and drop/recreate `trg_favorites_*` and `trg_songs_fts_*` triggers.
- `[Migrations.kt:MIGRATION_1_2]` .. `[Migrations.kt:MIGRATION_6_7]`: Execute `ALTER TABLE`, `CREATE TABLE`, `CREATE INDEX`, and table-rebuild SQL migrations on schema upgrades.
- All DAOs (`MusicDao`, `AlbumArtThemeDao`, `AudioBookmarkDao`, `EngagementDao`, `FavoritesDao`, `JellyfinDao`, `ListenBrainzDao`, `LocalPlaylistDao`, `LyricsDao`, `NavidromeDao`, `OfflineTrackDao`, `SearchHistoryDao`, `SyncedVideoDao`, `TransitionDao`): Read and mutate their respective Room SQLite tables (`songs`, `albums`, `artists`, `song_artist_cross_ref`, `songs_fts`, `album_art_themes`, `audio_bookmarks`, `song_engagements`, `favorites`, `jellyfin_*`, `listenbrainz_pending_listens`, `playlists`, `playlist_songs`, `lyrics`, `navidrome_*`, `offline_tracks`, `search_history`, `synced_videos`, `transition_rules`).
- `[PlaylistEntity.kt:PlaylistEntity]`, `[FavoritesEntity.kt:FavoritesEntity]`, `[AudioBookmarkEntity.kt:AudioBookmarkEntity]`, `[SongEntity.kt:SongEntity]`, `[SyncedVideoEntity.kt:SyncedVideoEntity]`, `[NavidromeSongEntity.kt:toEntity]`, `[JellyfinSongEntity.kt:toEntity]`: Read `System.currentTimeMillis()` for default timestamps.
