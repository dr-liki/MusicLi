# Preferences

## Overview
Manages application settings, UI/theme configuration, equalizer state, Room-backed playlists, smart-mix history, M3U sync state, and ListenBrainz scrobbling preferences under `com.drliki.MusicLi.data.preferences`.

## Interface
- `[UserPreferencesRepository.kt:UserPreferencesRepository]` — `@Singleton` DataStore-backed repository (`Context.dataStore` `"settings"`) exposing reactive `Flow`s and `suspend` mutators for playback/crossfade/audio output, library sorting & directory rules, artist parsing, lyrics & translation/romanization, theme/navigation/blur/discover UI tweaks, Explore cache/downloads/API endpoints (`DEFAULT_EXPLORE_API_BASE_URL`, `FALLBACK_EXPLORE_API_BASE_URL`, `exploreApiBaseUrlFlow`, `setExploreApiBaseUrl`), backup export/import (`exportPreferencesForBackup`, `importPreferencesFromBackup`, `clearPreferencesByKeys`, `clearPreferencesExceptKeys`), diagnostics (`AdvancedPerformanceDiagnosticsSettings`), and last-playlist tracking; includes `Companion.readUseFolderAlbumArtBlocking`, `[UserPreferencesRepository.kt:ThemePreference]`, `[UserPreferencesRepository.kt:AppThemeMode]`, `[UserPreferencesRepository.kt:AlbumArtQuality]`, `[UserPreferencesRepository.kt:EqualizerViewMode]`, `[UserPreferencesRepository.kt:MIN_NAV_BAR_CORNER_RADIUS]`, `[UserPreferencesRepository.kt:MAX_NAV_BAR_CORNER_RADIUS]`, `[UserPreferencesRepository.kt:sanitizeNavBarCornerRadius]`, internal `[UserPreferencesRepository.kt:normalizeExploreApiBaseUrl]`, and internal `[UserPreferencesRepository.kt:LocalAlbumGroupingSettings]`.
- `[ThemePreferencesRepository.kt:ThemePreferencesRepository]` — `@Singleton` repository for app/player theme mode, theme preset (`ThemePreset`), global Now Playing theme, interface typography/scale (`InterfaceAppearance`), and album-art palette style/accuracy (`appThemeModeFlow`, `playerThemePreferenceFlow`, `globalNowPlayingThemeEnabledFlow`, `themePresetFlow`, `interfaceAppearanceFlow`, `albumArtPaletteStyleFlow`, `albumArtColorAccuracyFlow`, and setters/`initializeAppThemeMode`).
- `[EqualizerPreferencesRepository.kt:EqualizerPreferencesRepository]` — `@Singleton` repository for equalizer enablement/preset/10-band custom levels, bass boost, virtualizer, loudness enhancer, view mode, pinned presets, and custom presets (`saveCustomPreset`, `deleteCustomPreset`, `renameCustomPreset`, `updateCustomPresetBands`).
- `[PlaylistPreferencesRepository.kt:PlaylistPreferencesRepository]` — `@Singleton` Room-backed playlist repository (`LocalPlaylistDao`, `TransitionDao`, `UserPreferencesRepository`) exposing `userPlaylistsFlow`, `playlistSongOrderModesFlow`, `playlistsSortOptionFlow`, and CRUD/reorder/bulk-replace operations.
- `[ListenBrainzPreferencesRepository.kt:ListenBrainzPreferencesRepository]` — `@Singleton` repository for per-source ListenBrainz scrobbling toggles (`scrobbleLocalFlow`, `scrobbleNavidromeFlow`, `scrobbleJellyfinFlow`, `isSourceEnabled`).
- `[M3uSyncPreferences.kt:M3uSyncPreferences]`, `[M3uSyncPreferences.kt:M3uSyncLink]`, `[M3uSyncPreferences.kt:M3uSyncConfig]`, `[M3uSyncPreferences.kt:withLinksIfSelectionMatches]` — `@Singleton` repository managing SAF M3U sync tree URI, revision, and link mappings (`disable`, internal `configFlow`, `snapshot`, `selectTree`, `replaceLinksIfSelection`).
- `[MixPreferences.kt:MixPreferences]` — `@Singleton` repository backed by `"smart_mix"` DataStore tracking recent smart-mix IDs, mix requests, and saved smart-mix playlist IDs.
- Value types, enums, and constants: `[AlbumArtColorAccuracy.kt:AlbumArtColorAccuracy]`, `[AlbumArtPaletteStyle.kt:AlbumArtPaletteStyle]`, `[AppLanguage.kt:AppLanguage]`, `[CarouselStyle.kt:CarouselStyle]`, `[CollagePattern.kt:CollagePattern]`, `[FullPlayerLoadingTweaks.kt:FullPlayerLoadingTweaks]`, `[LaunchTab.kt:LaunchTab]`, `[LibraryNavigationMode.kt:LibraryNavigationMode]`, `[LyricsDisplayPreferences.kt:LyricsWordHighlightStyle]` (+ `LYRICS_WORD_HIGHLIGHT_STYLE_KEY`, `LYRICS_DUET_LAYOUT_KEY`, `SHOW_LYRICS_BACKGROUND_VOCALS_KEY`, `DEFAULT_LYRICS_DUET_LAYOUT_ENABLED`, `DEFAULT_SHOW_LYRICS_BACKGROUND_VOCALS`), `[LyricsFontSize.kt:sanitizeLyricsFontSize]` (+ `MIN_LYRICS_FONT_SIZE_SP`, `MAX_LYRICS_FONT_SIZE_SP`, `DEFAULT_LYRICS_FONT_SIZE_SP`, `LYRICS_FONT_SIZE_SP_KEY`), `[NavBarStyle.kt:NavBarStyle]`, `[PreferenceBackupEntry.kt:PreferenceBackupEntry]`, `[PreviousButtonBehavior.kt:PreviousButtonBehavior]` (+ `PREVIOUS_BUTTON_RESTART_THRESHOLD_MS`, `restartsAtPosition`, `shouldRestartCurrentTrack`), `[SidebarShortcuts.kt:SidebarShortcutKeys]`, `[SwipeToQueueAction.kt:SwipeToQueueAction]`.

## Invariants
- `[UserPreferencesRepository.kt:UserPreferencesRepository.backupExcludedKeyNames]` excludes install-specific, migration-version, SAF tree, update, and credential keys (`listenbrainz_token`, `lastfm_session_key`, `INITIAL_SETUP_DONE`, `UPDATE_*`, etc.) from backup export, import overwrite, and `clearPreferencesByKeys`/`clearPreferencesExceptKeys`.
- `[UserPreferencesRepository.kt:UserPreferencesRepository]` clamps/normalizes values on read and write: nav bar corner radius `0..60`, crossfade duration `1000..12000ms`, playback speed via `PlaybackSpeedUtils.normalize`, min song duration `0..120000ms`, min tracks per artist `1..5`, player blur radius `8f..48f`, album art cache limit `50..1500 MB`, discover item count `3..20`, discover refresh interval `1..20 min`, lyrics font size `16f..42f` (`[LyricsFontSize.kt:sanitizeLyricsFontSize]`), and full-player thresholds `0..100`.
- `[UserPreferencesRepository.kt:UserPreferencesRepository]` enforces atomic multi-key invariants: `setDelayAllFullPlayerContent` updates all four element delay flags; `setFullPlayerPlaceholders(false)` disables transparent placeholders; `setExternalLyricsEnabled(false)` switches `API_FIRST` to `EMBEDDED_FIRST`; artist delimiter/extraction/grouping setters flag `ARTIST_SETTINGS_RESCAN_REQUIRED = true`; `updateAllowedDirectories`/`updateDirectorySelections` reset `LAST_SYNC_TIMESTAMP` to `0L` and increment `DIRECTORY_RULES_VERSION`; `setGroupLocalAlbumsByTitle` increments `LOCAL_ALBUM_GROUPING_REVISION`.
- `[UserPreferencesRepository.kt:UserPreferencesRepository.migrateTabOrder]` and `[UserPreferencesRepository.kt:UserPreferencesRepository.migrateGenresTab]` are one-shot guarded migrations that abort without modifying `LIBRARY_TABS_ORDER` on JSON parse failure; `[UserPreferencesRepository.kt:UserPreferencesRepository.ensureLibrarySortDefaults]` migrates legacy song sort defaults once.
- `[UserPreferencesRepository.kt:AdvancedPerformanceDiagnosticsSettings.isActive]` and `[UserPreferencesRepository.kt:UserPreferencesRepository.disableExpiredAdvancedPerformanceDiagnostics]` expire diagnostic sessions once `nowEpochMs >= expiresAtEpochMs`.
- `[PlaylistPreferencesRepository.kt:PlaylistPreferencesRepository.ensureMigratedIfNeeded]` runs legacy playlist migration once under `migrationMutex` + `@Volatile migrationChecked` only when Room playlist count is `0`; playlist song mutation methods (`addSongsToPlaylist`, `addOrRemoveSongFromPlaylists`, `removeSongFromPlaylist`, `reorderSongsInPlaylist`) skip or reject `isSmartPlaylist` playlists.
- `[EqualizerPreferencesRepository.kt:EqualizerPreferencesRepository]` normalizes custom equalizer bands to exactly `10` integers, coerces bass/virtualizer/loudness strengths to `0..1000`, and updates pinned/active preset references on `renameCustomPreset`.
- `[M3uSyncPreferences.kt:M3uSyncPreferences.replaceLinksIfSelection]` atomically checks `expectedTreeUri` and `expectedRevision` inside `dataStore.edit` before committing links.
- `[MixPreferences.kt:MixPreferences]` bounds smart-mix freshness to `7` days across `3` ring-buffer slots (`<= 200` IDs/slot) and caps recent mix requests at `6` entries (`<= 80` chars).
- `[ThemePreferencesRepository.kt:ThemePreferencesRepository.initializeAppThemeMode]` writes `app_theme_mode` only when unset; `[ThemePreferencesRepository.kt:ThemePreset.sanitize]` allows only `default`/`amoled`; `[ThemePreferencesRepository.kt:InterfaceAppearance.sanitizeScale]` allows only `90`, `100`, `110`, `120`; `[AlbumArtColorAccuracy.kt:AlbumArtColorAccuracy.clamp]` clamps to `0..10`.
- `[AppLanguage.kt:AppLanguage.normalize]` falls back to `SYSTEM.tag`; `[PreviousButtonBehavior.kt:PreviousButtonBehavior.restartsAtPosition]` triggers restart only for `RESTART_TRACK` when `positionMs > 10_000L` (or `!hasPrevious`).

## Side Effects
- `[UserPreferencesRepository.kt:UserPreferencesRepository]`, `[ThemePreferencesRepository.kt:ThemePreferencesRepository]`, `[EqualizerPreferencesRepository.kt:EqualizerPreferencesRepository]`, `[ListenBrainzPreferencesRepository.kt:ListenBrainzPreferencesRepository]`, and `[M3uSyncPreferences.kt:M3uSyncPreferences]` read from and edit `"settings"` Jetpack DataStore on disk.
- `[UserPreferencesRepository.kt:UserPreferencesRepository.setLyricsRomanizationStyle]` mutates global `MultiLangRomanizer.preferredIndicStyle`; `[UserPreferencesRepository.kt:UserPreferencesRepository.Companion.readUseFolderAlbumArtBlocking]` performs a blocking `runBlocking` DataStore read.
- `[MixPreferences.kt:MixPreferences]` creates and edits a dedicated `"smart_mix"` Jetpack DataStore on disk.
- `[PlaylistPreferencesRepository.kt:PlaylistPreferencesRepository]` reads and mutates Room `LocalPlaylistDao` and `TransitionDao` tables and delegates sort/order preferences to `UserPreferencesRepository`.
