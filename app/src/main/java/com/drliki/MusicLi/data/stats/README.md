# Stats

## Overview
Records local playback history and computes time-range statistics, listening sessions, daily listening distributions, and annual Listening Recap summaries under `com.drliki.MusicLi.data.stats`.

## Interface
- `[PlaybackStatsRepository.kt:PlaybackStatsRepository]` — `@Singleton` repository exposing `[PlaybackStatsRepository.kt:PlaybackStatsRepository.refreshFlow]` (`StateFlow<Long>`), `[PlaybackStatsRepository.kt:PlaybackStatsRepository.recordPlayback]`, `[PlaybackStatsRepository.kt:PlaybackStatsRepository.loadPlayedSongIds]`, `[PlaybackStatsRepository.kt:PlaybackStatsRepository.loadSummary]`, `[PlaybackStatsRepository.kt:PlaybackStatsRepository.loadRecap]`, `[PlaybackStatsRepository.kt:PlaybackStatsRepository.loadRecapYearTotals]`, `[PlaybackStatsRepository.kt:PlaybackStatsRepository.exportEventsForBackup]`, `[PlaybackStatsRepository.kt:PlaybackStatsRepository.loadPlaybackHistory]`, `[PlaybackStatsRepository.kt:PlaybackStatsRepository.importEventsFromBackup]`, `[PlaybackStatsRepository.kt:PlaybackStatsRepository.requestRefresh]`, and internal aggregation entry points `buildSummaryFromEvents`, `buildRecapFromEvents`, `recapYearTotals`.
- `[PlaybackStatsRepository.kt:StatsTimeRange]` — Time window enum (`DAY`, `WEEK`, `MONTH`, `YEAR`, `ALL`).
- Stats DTOs in `PlaybackStatsRepository.kt`: `[PlaybackStatsRepository.kt:PlaybackEvent]`, `[PlaybackStatsRepository.kt:PlaybackHistoryEntry]`, `[PlaybackStatsRepository.kt:SongPlaybackSummary]`, `[PlaybackStatsRepository.kt:ArtistPlaybackSummary]`, `[PlaybackStatsRepository.kt:GenrePlaybackSummary]`, `[PlaybackStatsRepository.kt:AlbumPlaybackSummary]`, `[PlaybackStatsRepository.kt:TimelineEntry]`, `[PlaybackStatsRepository.kt:PlaybackSegment]`, `[PlaybackStatsRepository.kt:PlaybackSpan]`, `[PlaybackStatsRepository.kt:DayListeningDistribution]`, `[PlaybackStatsRepository.kt:DailyListeningBucket]`, `[PlaybackStatsRepository.kt:DailyListeningDay]`, `[PlaybackStatsRepository.kt:PlaybackStatsSummary]`, plus internal constants `UNKNOWN_ARTIST`, `UNKNOWN_ALBUM`, `UNKNOWN_GENRE`.
- `[ListeningRecap.kt:ListeningRecap]`, `[ListeningRecap.kt:RecapSong]`, `[ListeningRecap.kt:ListeningPersonality]`, `[ListeningRecap.kt:RecapYearTotal]` — Annual recap models and personality classification (`EARLY_BIRD`, `DAYTIME`, `EVENING`, `NIGHT_OWL`).
- `[ListeningRecapMath.kt:recapYearBounds]`, `[ListeningRecapMath.kt:hourlyDurations]`, `[ListeningRecapMath.kt:classifyPersonality]`, `[ListeningRecapMath.kt:dominantDecade]`, `[ListeningRecapMath.kt:peakIndex]`, `[ListeningRecapMath.kt:RecapBounds]`, `[ListeningRecapMath.kt:DecadeShare]`, `[ListeningRecapMath.kt:RecapYearRange]` — Internal date-bound, hourly-slicing, personality, and decade calculations.

## Invariants
- `[PlaybackStatsRepository.kt:PlaybackStatsRepository.updateEventsAtomically]` serializes history reads/writes and `cachedEvents` updates under `fileLock` with `AtomicFile` and up to `3` optimistic retry passes before fallback locked write; `[PlaybackStatsRepository.kt:PlaybackStatsRepository.notifyStatsChanged]` increments `_refreshVersion` monotonically (wrapping `Long.MAX_VALUE` to `1L`).
- `[PlaybackStatsRepository.kt:PlaybackStatsRepository.recordPlayback]` ignores blank `songId`, clamps `timestamp` and `durationMs` `>= 0L`, and prunes events older than `MAX_HISTORY_AGE_MS` (`730` days); `[PlaybackStatsRepository.kt:PlaybackStatsRepository.sanitizeEvent]` enforces non-negative durations and `startTimestamp <= endTimestamp`.
- `[PlaybackStatsRepository.kt:PlaybackStatsRepository.importEventsFromBackup]` sanitizes, deduplicates by `songId:startMillis:endMillis:durationMs`, and sorts events ascending by `timestamp`; `[PlaybackStatsRepository.kt:PlaybackStatsRepository.loadPlaybackHistory]` returns `emptyList()` for `limit <= 0` and caps at `MAX_PLAYBACK_HISTORY_LIMIT` (`5000`).
- `[PlaybackStatsRepository.kt:PlaybackStatsRepository.buildSummaryFromEvents]` clips spans to range bounds, merges adjacent/overlapping segments (`SEGMENT_JOIN_TOLERANCE_MS = 0L`), splits listening sessions at `sessionGapThresholdMs` (`30` minutes), caps `songs` at `MAX_SONG_STATS_COUNT` (`100`) and top rankings at `rankingLimit` (default `5`), and computes `5`-minute `dayListeningDistribution` buckets only for `DAY` and `WEEK`.
- `[ListeningRecapMath.kt:recapYearBounds]` rejects years outside `1970..9999` or years starting after `nowMillis`; `[ListeningRecapMath.kt:hourlyDurations]` returns a 24-element array splitting spans across local hour and DST boundaries; `[ListeningRecapMath.kt:dominantDecade]` requires plausible release years (`1900..2100`), `>= 30%` tagged listening coverage, and `>= 25%` top-decade share.

## Side Effects
- `[PlaybackStatsRepository.kt:PlaybackStatsRepository]` reads and atomically writes/fsyncs `filesDir/playback_history.json` via `AtomicFile` on `Dispatchers.IO`, mutates in-memory `cachedEvents`, updates `refreshFlow`, reads Android string resource `R.string.presentation_batch_g_stats_week_label`, and logs I/O or JSON parse errors via `Timber`.
