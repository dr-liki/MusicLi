# screens

## Overview
Top-level Jetpack Compose presentation screens, tab views, onboarding pages, modal workflows, and supporting UI models/helpers for `com.drliki.MusicLi.presentation.screens`. Covers home, library browsing (songs, albums, artists, playlists, folders, genres, favorites), search, detail views (album, artist, genre, playlist, recently played, daily mix), playback utilities (equalizer, mashup, audio bookmarks, transition editor), online explore/downloads, stats, device diagnostics, storage management, updates, licensing, and settings/setup flows.

## Invariants
- **Android API & Hardware Gates**: `LibraryScreen` is `@RequiresApi(Build.VERSION_CODES.R)` (`[LibraryScreen.kt:LibraryScreen]`); `SetupScreen` only includes `NotificationsPermission` on `SDK_INT >= TIRAMISU` and `AlarmsPermission` on `SDK_INT >= S`, and enforces `allRequiredPermissionsGrantedNow(context)` before finishing and `firstBlockedForwardPageIndex` when advancing (`[SetupScreen.kt:SetupScreen]`, `[SetupScreen.kt:NotificationsPermissionPage]`, `[SetupScreen.kt:AlarmsPermissionPage]`); `SettingsCategoryScreen` gates blur toggles on `Build.VERSION.SDK_INT >= Build.VERSION_CODES.S`, high-refresh-rate toggle on `maxDisplayRefreshHz > 61`, folder album art on `folderArtworkPermissions(Build.VERSION.SDK_INT)`, and audio output options (`PCM_FLOAT`, `BIT_PERFECT_USB`) on capability flags (`[SettingsCategoryScreen.kt:SettingsCategoryScreen]`).
- **Collapsible Top Bar & Nested Scroll Bounds**: Collapsible screens (`AboutScreen`, `AccountsScreen`, `AlbumDetailScreen`, `ArtistDetailScreen`, `ArtistSettingsScreen`, `AudioBookmarksScreen`, `BulkLyricsEmbedScreen`, `DelimiterConfigScreen`, `DeviceCapabilitiesScreen`, `EqualizerScreen`, `ExperimentalSettingsScreen`, `GenreDetailScreen`, `LicensesScreen`, `LyricsSettingsScreen`, `SettingsCategoryScreen`, `SettingsScreen`, `StatsScreen`, `WordDelimiterConfigScreen`) clamp `topBarHeight` `Animatable` strictly within `[minTopBarHeightPx, maxTopBarHeightPx]`, derive `collapseFraction` in `0f..1f`, ignore upward/expand scroll while `firstVisibleItemIndex > 0 || firstVisibleItemScrollOffset > 0`, and settle to expanded only at `(0, 0)` past the midpoint or fling threshold (`[AboutScreen.kt:AboutScreen]`, `[GenreDetailScreen.kt:GenreDetailScreen]`, `[StatsScreen.kt:StatsScreen]`).
- **Selection, Back Handling & Concurrency Guards**: Detail/library/search screens (`ArtistDetailScreen`, `GenreDetailScreen`, `LibraryScreen`, `PlaylistDetailScreen`, `SearchScreen`) isolate per-scope selection, use `PlayerSheetAwareBackHandler` enabled only when selection/folder-back is active, read `selectedSongIds.value` directly for drag-select, and clear stale resolved selections on toggle or tab switch (`[LibraryScreen.kt:LibraryScreen]`, `[GenreDetailScreen.kt:GenreDetailScreen]`, `[SearchScreen.kt:SearchScreen]`); `SearchScreen` caps album multi-selection at `MAX_ALBUM_MULTI_SELECTION = 6` (`[SearchScreen.kt:MAX_ALBUM_MULTI_SELECTION]`); `PlaylistDetailScreen` keys reorder/selection items by `(entry.index, song.id)` to disambiguate duplicate songs and disables edit/reorder/remove controls on folder or smart playlists (`[PlaylistDetailScreen.kt:PlaylistDetailScreen]`); `AudioBookmarksScreen` registers `fabMenuExpanded` back handler before `isSelecting` back handler (`[AudioBookmarksScreen.kt:AudioBookmarksScreen]`).
- **Paging Scroll & Sort Reset**: `rememberRestoredLazyListState` and `rememberRestoredLazyGridState` wait up to `5_000L` ms for `items.itemCount > savedIndex` before restoring `(0, 0)` and suppress scroll saving until restored (`[LibraryScrollRestore.kt:rememberRestoredLazyListState]`, `[LibraryScrollRestore.kt:rememberRestoredLazyGridState]`); `ResetScrollOnSortChange` waits up to `1_000L` ms for `LoadState.Loading` and `10_000L` ms for completion before re-scrolling to top (`[LibrarySortScrollReset.kt:ResetScrollOnSortChange]`); `LibraryAlbumsTab`, `LibraryArtistsTab`, `LibrarySongsTab`, and `LibraryFavoritesTab` substitute dummy scroll states when `itemCount == 0` and bounds-check `peek(index)` (`[LibraryMediaTabs.kt:LibraryAlbumsTab]`, `[LibrarySongsTab.kt:LibrarySongsTab]`).
- **Domain Configuration & Input Validation**: `DelimiterConfigScreen` requires at least 1 artist delimiter (`uiState.artistDelimiters.size > 1`) and non-blank additions (`[DelimiterConfigScreen.kt:DelimiterConfigScreen]`); `LyricsSettingsScreen` requires at least 1 enabled lyrics provider (`!isEnabled || enabledLyricsProviders.size > 1`) and bounds font/blur sliders (`[LyricsSettingsScreen.kt:LyricsSettingsScreen]`); `NavBarCornerRadiusContent` clamps radii to `MIN_NAV_BAR_CORNER_RADIUS..MAX_NAV_BAR_CORNER_RADIUS` (`[NavBarCornerRadiusScreen.kt:NavBarCornerRadiusContent]`); `PaletteAccuracySlider` clamps values via `AlbumArtColorAccuracy.clamp` and suppresses duplicate dispatches (`[PaletteStyleSettingsScreen.kt:PaletteAccuracySlider]`); `EqualizerScreen` clamps band levels to `-15f..15f`, `CustomVerticalSlider` normalizes to `0f..1f`, and `resolveVerticalSliderFillColor` returns `null` when `active.alpha == 0f` (`[EqualizerScreen.kt:EqualizerScreen]`, `[EqualizerScreen.kt:resolveVerticalSliderFillColor]`); `SettingsCategoryScreen` disables export/import during `isDataTransferInProgress`, enforces a `1500L` ms minimum progress dialog display (`BackupTransferDialogMinimumVisibilityMs`), and blocks dismissal/actions during bulk palette regeneration or backup password inspection (`[SettingsCategoryScreen.kt:SettingsCategoryScreen]`, `[SettingsCategoryScreen.kt:BackupTransferProgressDialogHost]`).
- **Empty, Blank & Zero-Division Guards**: `SettingsCategoryScreen` returns early when `SettingsCategory.fromId(categoryId) == null` (`[SettingsCategoryScreen.kt:SettingsCategoryScreen]`); `StatsScreen` guards `playCount > 0` in `AverageSession`, `leader.durationMs.coerceAtLeast(1L)`, and `varietySlices` total duration (`[StatsScreen.kt:ListeningHabitsGrid]`, `[StatsScreen.kt:HeavyRotationSection]`, `[StatsScreen.kt:varietySlices]`); `StorageBreakdownBar` clamps denominators to `.coerceAtLeast(1L)` (`[StorageSenseScreen.kt:StorageBreakdownBar]`); `AudioBookmarkModels` validates `collapsedItemSizePx > 0`, `bookmarkLastFocusableIndex` (`folderCount > 0`), and `bookmarkTitleWidthAxisForText` (`84f..132f`) (`[AudioBookmarkModels.kt:bookmarkStableFocusGeometries]`, `[AudioBookmarkModels.kt:bookmarkTitleWidthAxisForText]`); `CreatePlaylistContent` and `EditPlaylistContent` keep cover fields tab-exclusive (`[CreatePlaylistScreen.kt:CreatePlaylistContent]`, `[CreatePlaylistScreen.kt:EditPlaylistContent]`).

## Side Effects
- **ViewModel & Repository State Mutations**: Screens collect `StateFlow`/`Flow` streams with lifecycle (`collectAsStateWithLifecycle`, `repeatOnLifecycle(Lifecycle.State.STARTED)`) and dispatch mutations to `PlayerViewModel`, `SettingsViewModel`, `PlaylistViewModel`, `LibraryViewModel`, `EqualizerViewModel`, `MashupViewModel`, `TransitionViewModel`, `AudioBookmarksViewModel`, `ExploreViewModel`, `CloudDownloadsViewModel`, `StorageSenseViewModel`, `StatsViewModel`, `SmartMixViewModel`, `UpdatesViewModel`, `AccountsViewModel`, `ArtistSettingsViewModel`, `DeviceCapabilitiesViewModel`, `BulkLyricsEmbedViewModel`, `M3uSyncViewModel`, and `SetupViewModel` (`[LibraryScreen.kt:LibraryScreen]`, `[SettingsCategoryScreen.kt:SettingsCategoryScreen]`, `[EqualizerScreen.kt:EqualizerScreen]`, `[SetupScreen.kt:SetupScreen]`).
- **Playback, Queue & Audio Hardware Control**: Playback screens invoke `showAndPlaySong`, `playSongs`, `playSongsShuffled`, `playSongAtPosition`, `playRandomSong`, `playAlbum`, `playArtist`, `addSongToQueue`, `addSongNextToQueue`, `toggleShuffle`, equalizer preset/effect/volume setters, and dual-deck mashup controls (`[AlbumDetailScreen.kt:AlbumDetailScreen]`, `[AudioBookmarksScreen.kt:AudioBookmarkFolderScreen]`, `[EqualizerScreen.kt:EqualizerScreen]`, `[MashupScreen.kt:MashupScreen]`, `[SearchScreen.kt:SearchResultsList]`).
- **System Launchers, Permissions, Filesystem & Backup I/O**: `CreateDocument`, `OpenDocumentTree`, `GetContent`, `StartIntentSenderForResult`, and multiple-permission launchers handle M3U import/export, backup export/import, SAF export folders (including `takePersistableUriPermission`), MediaStore write permissions, and custom artist/playlist artwork selection (`[BulkLyricsEmbedScreen.kt:BulkLyricsEmbedScreen]`, `[CloudDownloadsScreen.kt:CloudDownloadsScreen]`, `[CreatePlaylistScreen.kt:CreatePlaylistContent]`, `[ExploreDownloadsScreen.kt:ExploreDownloadsScreen]`, `[LibraryScreen.kt:LibraryScreen]`, `[PlaylistDetailScreen.kt:PlaylistDetailScreen]`, `[SettingsCategoryScreen.kt:SettingsCategoryScreen]`); `LicensesScreen` reads bundled notice/license assets on `Dispatchers.IO` (`[LicensesScreen.kt:readAssetText]`); `LibraryFoldersTab` inspects parent directories via `java.io.File` (`[LibraryScreen.kt:LibraryFoldersTab]`).
- **Navigation, External Activities, Clipboard & System UI**: Screens navigate via `NavController` (`navigateSafely`, `navigateSafelyReplacing`, `popBackStack`, `navigateUp`), launch external Activities (`ACTION_VIEW`, `ACTION_SEND` share sheets, `ACTION_MANAGE_UNKNOWN_APP_SOURCES`, `ACTION_DELETE`, `ACTION_REQUEST_SCHEDULE_EXACT_ALARM`, battery optimization settings, `NavidromeLoginActivity`, `JellyfinLoginActivity`, `(context as? Activity)?.recreate()`), write to system `ClipboardManager`, and update status bar appearance via `PixelPlayerStatusBarStyle` (`[AboutScreen.kt:openUrl]`, `[AccountsScreen.kt:openService]`, `[ArtistDetailScreen.kt:SharedArtistTopBarProbe]`, `[DeviceCapabilitiesScreen.kt:PerformanceReportCard]`, `[SetupScreen.kt:SetupLanguagePill]`, `[UpdatesScreen.kt:UpdatesScreen]`).
- **Feedback, Haptics, Tracing & Image Loading**: Triggers `Toast` / `Snackbar` messages, haptic feedback (`HapticFeedbackType`, `HapticFeedbackConstantsCompat`), Coil `SmartImage`/`AsyncImage`/prefetch `ImageLoader` requests, `traceSection` / `ReportDrawnWhen` / `AdvancedPerformanceDiagnostics`, and `Timber` logging (`[HomeScreen.kt:HomeScreen]`, `[LibraryMediaTabs.kt:LibraryAlbumsTab]`, `[SearchScreen.kt:SearchScreen]`, `[StorageSenseScreen.kt:StorageSenseScreen]`).
