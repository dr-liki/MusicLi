# Presentation Components

## Overview
Provides the primary Jetpack Compose UI component library for MusicLi (`com.drliki.MusicLi.presentation.components`). It houses the unified expandable player sheet and overlay layers, synchronized/plain lyrics sheet and word-highlighting renderers, reorderable queue bottom sheet, song/album/playlist/genre bottom sheets and multi-selection controllers, media detail hero and collapsible top bars, home discovery/recently-played/stats cards, smart-mix composer, tag/cover-art editors, file/cloud pickers, custom wavy sliders, fast-scrollbars, and shared artwork/marquee primitives, while delegating specialized subsystems to its six child packages.

## Interface

### Child Component Packages
- [BrickBreaker](./brickbreaker/README.md) - Interactive Brick Breaker easter-egg minigame overlay (`BrickBreakerOverlay`, `BrickType`).
- [External](./external/README.md) - External playback modal overlay (`ExternalPlayerOverlay`).
- [Player](./player/README.md) - Full-screen adaptive player UI, embedded queue/lyrics panes, transport controls, and audio-details/output/speed/artist sheets (`FullPlayerContent`, `EmbeddedQueuePane`, `EmbeddedLyricsPane`, etc.).
- [Scoped](./scoped/README.md) - Scoped state holders, gesture handlers, predictive back handlers, motion controllers, layout math, and runtime policies for the unified player sheet (`SheetMotionController`, `QueueSheetController`, `SheetOverlayState`, etc.).
- [Snapping](./snapping/README.md) - `LazyListState` item-snapping fling mechanics (`SnapperFlingBehavior`, `LazyListSnapperLayoutInfo`, `rememberSnapperFlingBehavior`).
- [Subcomps](./subcomps/README.md) - Leaf-level shared UI primitives including auto-sizing text, song list items, action/selection rows, lyrics dialogs/sheets, seek bars, and waveform/EQ icons (`EnhancedSongListItem`, `PlayerSeekBar`, `PlayingEqIcon`, etc.).
