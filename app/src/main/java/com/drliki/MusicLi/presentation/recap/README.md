# Recap

## Overview
Implements the annual listening recap ("Wrapped"/year-in-review) presentation layer under `presentation.recap`. Covers entry cards for Stats and Home (`RecapEntryCards.kt`), seasonal scheduling and eligibility thresholds (`RecapSchedule.kt`), duration/chart formatting (`RecapFormats.kt`), theme-derived palettes and animated typography/backdrop building blocks (`RecapComponents.kt`), immutable slide/UI state models (`RecapUiModels.kt`), full-screen auto-advancing story playback (`RecapScreen.kt`), all 11 slide layouts (`RecapSlides.kt`, `RecapSummary.kt`), and PNG share-sheet export (`RecapShare.kt`).

## Interface
- `[RecapScreen.kt:RecapScreen]`: `@Composable fun RecapScreen(navController: NavController, playerViewModel: PlayerViewModel, recapViewModel: RecapViewModel = hiltViewModel())`.
- `[RecapEntryCards.kt:RecapStatsCard]`, `[RecapEntryCards.kt:RecapHomeCard]`: Public `@Composable` entry cards for Stats (`entries: ImmutableList<RecapEntry>, onOpen: (year: Int) -> Unit`) and Home (`entry: RecapEntry, onOpen: () -> Unit, onDismiss: () -> Unit`).
- `[RecapSchedule.kt:RecapEntry]`, `[RecapSchedule.kt:RecapSchedule]`: `@Immutable data class RecapEntry(year: Int, isSoFar: Boolean)` and `internal object RecapSchedule` (`MIN_RECAP_LISTENING_MS`, `homeCardYear`, `isSoFar`, `hasEnoughListening`, `statsEntries`).
- `[RecapUiModels.kt:RECAP_RANKING_SIZE]`, `[RecapUiModels.kt:RecapUiState]`, `[RecapUiModels.kt:RecapUiModel]`, `[RecapUiModels.kt:RecapArtistItem]`, `[RecapUiModels.kt:RecapAlbumItem]`, `[RecapUiModels.kt:RecapSongItem]`, `[RecapUiModels.kt:RecapGenreItem]`, `[RecapUiModels.kt:RecapSlide]`, `[RecapUiModels.kt:buildRecapSlides]`: `RECAP_RANKING_SIZE = 5`; `@Immutable` state/item models and `sealed interface RecapSlide` (`Intro`, `Minutes`, `Months`, `Clock`, `Dedication`, `Genres`, `Decade`, `TopAlbums`, `TopArtists`, `TopSongs`, `Summary`) built via `internal fun buildRecapSlides(...)`.
- `[RecapSlides.kt:RecapSummaryActions]`, `[RecapSlides.kt:RecapSlideContent]`, `[RecapSlides.kt:ListeningPersonality.titleRes]`: Slide action callbacks (`onShare: (GraphicsLayer) -> Unit`, `onPlayTopSongs`, `onReplay`), page dispatcher composable, and personality title resource mapping.
- `[RecapSummary.kt:RecapSummarySlide]`, `[RecapSummary.kt:hasContent]`: Summary slide composable capturing the shareable card into a `GraphicsLayer` and `GraphicsLayer.hasContent: Boolean`.
- `[RecapComponents.kt:RecapPalette]`, `[RecapComponents.kt:rememberRecapPalettes]`, `[RecapComponents.kt:forPage]`, `[RecapComponents.kt:rememberRecapFlexFont]`, `[RecapComponents.kt:revealFraction]`, `[RecapComponents.kt:revealSpan]`, `[RecapComponents.kt:recapReveal]`, `[RecapComponents.kt:rememberRecapMotionEnabled]`, `[RecapComponents.kt:rememberSpin]`, `[RecapComponents.kt:RecapSlideColumn]`, `[RecapComponents.kt:RecapKicker]`, `[RecapComponents.kt:RecapHeadline]`, `[RecapComponents.kt:RecapBody]`, `[RecapComponents.kt:RecapCountUpText]`, `[RecapComponents.kt:RecapChip]`, `[RecapComponents.kt:RecapStatTile]`, `[RecapComponents.kt:rememberMonogram]`, `[RecapComponents.kt:RecapArtwork]`, `[RecapComponents.kt:RecapRankRow]`, `[RecapComponents.kt:RecapMorphBlob]`, `[RecapComponents.kt:RecapProgressBar]`, `[RecapComponents.kt:RecapBackdropShape]`: Shared palette, motion, typography, and chart UI primitives (`RECAP_REVEAL_DURATION_MS = 1500`, `RecapGutter = 28.dp`).
- `[RecapFormats.kt:formatRecapDuration]`, `[RecapFormats.kt:recapListenedMinutes]`, `[RecapFormats.kt:recapChartEntries]`: Duration and chart entry formatting helpers.
- `[RecapShare.kt:shareRecapImage]`: `internal suspend fun shareRecapImage(context: Context, layer: GraphicsLayer, year: Int)`.

## Invariants
- `[RecapSchedule.kt:RecapSchedule]`: `homeCardYear` returns `today.year` in December, `today.year - 1` on January `1..15`, and `null` otherwise; `isSoFar` is `true` only when `year == today.year && today.month != Month.DECEMBER`; `hasEnoughListening` requires `listenedMs >= MIN_RECAP_LISTENING_MS` (30 minutes); `statsEntries` checks only `today.year` and `today.year - 1`.
- `[RecapUiModels.kt:buildRecapSlides]`: Always emits `Intro`, `Minutes`, and `Summary`; optional slides emit only when non-empty/non-null data exists after filtering `UNKNOWN_ARTIST`, `UNKNOWN_ALBUM`, `UNKNOWN_GENRE`, `GenreParser.isSourcePlaceholder(...)`, and `totalDurationMs <= 0L`; caps rankings at `RECAP_RANKING_SIZE` (5) and clamps genre `share` to `[0f, 1f]`.
- `[RecapScreen.kt:RecapStory]`: Auto-advance (`SLIDE_DURATION_MS = 7_000` under `UnscaledMotion`) pauses whenever held, user-paused, not `Lifecycle.State.RESUMED`, or scrolling; leaving `RESUMED` or pausing cancels `autoMove` (`cancelAndJoin()`) and snaps to `currentPage`; tap navigation uses `PREVIOUS_TAP_ZONE = 0.3f` mirrored for `LayoutDirection.Rtl`.
- `[RecapScreen.kt:RecapScreen]`, `[RecapSummary.kt:hasContent]`, `[RecapShare.kt:shareRecapImage]`: Share checks `layer.hasContent` (`size.width > 0 && size.height > 0`), rethrows `CancellationException`, converts `Bitmap.Config.HARDWARE` to `ARGB_8888`, asserts `bitmap.compress(...)`, and adds `Intent.FLAG_ACTIVITY_NEW_TASK` for non-`Activity` contexts.
- `[RecapSlides.kt:MonthsSlide]`, `[RecapSlides.kt:ClockSlide]`, `[RecapSlides.kt:DedicationSlide]`, `[RecapSlides.kt:GenresSlide]`, `[RecapSlides.kt:AlbumsSlide]`, `[RecapSlides.kt:ArtistsSlide]`, `[RecapSlides.kt:SongsSlide]`: `MonthsSlide` requires `peakMonthIndex` in `0..11`; `ClockSlide` expects `HOURS_PER_DAY = 24` labels and pins `0/6/12/18` with `AbsoluteAlignment` so the clock never mirrors in RTL; `DedicationSlide` formats `biggestDay` at 12:00 UTC (`TimeZone.GMT_ZONE`); ranking slides require non-empty lists and `RecapSlideContent` clips to bounds.
- `[RecapComponents.kt:rememberRecapMotionEnabled]`, `[RecapComponents.kt:forPage]`, `[RecapComponents.kt:rememberRecapFlexFont]`, `[RecapComponents.kt:RecapProgressBar]`: Motion is enabled iff `Settings.Global.ANIMATOR_DURATION_SCALE > 0f`; `forPage` uses `page.mod(size)`; `rememberRecapFlexFont` clamps `width` to `25f..151f`; `RecapProgressBar` mirrors in RTL and returns early if `count <= 0`.

## Side Effects
- `[RecapScreen.kt:RecapScreen]`, `[RecapScreen.kt:RecapStory]`: Collects `recapViewModel.uiState`, invokes `navController.popBackStack()`, starts queue playback via `playerViewModel.playSongs(...)`, triggers `HapticFeedbackType.SegmentTick`, shows `Toast` on share error, and logs via `Timber.e`.
- `[RecapScreen.kt:RecapSystemBarsAppearance]`, `[RecapScreen.kt:rememberTouchExplorationEnabled]`: Mutates `WindowInsetsControllerCompat` light status/nav bar appearance and restores on dispose; registers/unregisters `AccessibilityManager.TouchExplorationStateChangeListener`.
- `[RecapComponents.kt:rememberRecapMotionEnabled]`: Reads `Settings.Global.ANIMATOR_DURATION_SCALE` and registers a `ContentObserver` on `Looper.getMainLooper()`.
- `[RecapSummary.kt:RecapSummarySlide]`, `[RecapShare.kt:shareRecapImage]`: Records summary card draw commands into `GraphicsLayer`, renders to `Bitmap`, writes `cacheDir/recap/recap_<year>.png` on `Dispatchers.IO`, and launches Android share chooser via `FileProvider`.
