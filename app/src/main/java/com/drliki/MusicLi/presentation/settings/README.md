# settings

## Overview
Groups settings-related presentation subpackages under `presentation.settings`, currently housing the searchable settings catalog, fuzzy ranking engine, result components, and highlight modifier.

## Subdirectories & Boundaries
- `search`: [./search/README.md](./search/README.md) - `SettingsRegistry`, `SettingsFuzzySearchEngine`, `SettingSpec`, `SettingsSearchComponents`, and `SettingHighlightModifier` for settings search and one-shot row highlighting.
